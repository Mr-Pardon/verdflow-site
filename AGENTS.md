# VerdFlow Site

This is the independent public-facing VerdFlow website and Chinese user manual.
Read README.md and CONTENT_GUIDE.md before editing. Do not modify the sibling
VerdFlow product repository as part of website changes.

- Use VitePress 1.x, Vue and Markdown. The site is static and deploys to GitHub Pages.
- Public pages must not contain local paths, credentials, private project names or internal diagnostics.
- Base claims on verified product behavior. Distinguish development improvements from shipped releases.
- Catalogs are mutable indexes, not installed 3D resources. Profiles are self-contained vegetation mixes.
- Strategy roles are spatial responsibilities, not species. Preserve exact strategy-version semantics.
- Screenshots must identify synthetic demonstration data. Generated scenery is never labeled as a product result.
- Keep downloads honest: configure a real release URL before enabling a binary-download action.
- Run npm run check, npm run build and npm test before handing off substantial changes.
- Verify responsive navigation, search, links, screenshots and keyboard accessibility.
- Never commit node_modules, screenshots containing private data, binary release packages or build outputs.
