# 调参时查看效果示意

<p class="lead">先在小样本上理解疏密和构图，再把确认好的配置用于实际区域。</p>

## 打开效果示意

在 Studio 工作台的手动配置中，进入 **效果与预览**。支持示例的策略会把参数与样本画布并排显示。

<Shot src="/media/studio-effect-example-v031.webp" alt="Studio 效果与预览面板，左侧调整间距和覆盖率，右侧显示群落样本点位" caption="0.3.1 真实组件；点位由内置策略在包内合成样本上生成，不使用私人项目" />

实时面板在 **构图参数**或预设方案摘要中提供 **效果示意**按钮，点击后打开附属侧板。可以保持侧板打开，同时调整主面板参数；关闭侧板不会删除当前配置。

## 怎样比较参数

1. 先保留默认值，观察样本里的铺底、主景或组团关系。
2. 一次只改变一个间距、覆盖率或密度参数，等待示例更新。
3. 配置植被后，再结合参考范围检查视觉尺度。
4. 对实际选区执行生成，在正式点位预览或 DTS 场景中确认结果。

样本边界与种子由策略包固定。改变正式种植的随机种子不会让示例随机换一幅图，方便比较参数本身的影响。旧图在更新期间可能暂时保留，以面板状态为准。

## 三种画面各自说明什么

| 画面 | 数据来源 | 用途 |
| --- | --- | --- |
| 植被用途的静态示意 | 作者随策略声明的位置关系 | 理解一个用途应该选什么植物 |
| 调参时的效果示意 | 原生成器在策略自带小样本上的结果 | 比较参数、用途开关与素材尺度 |
| 项目点位预览 | 当前区域实际生成并分配植被的点位 | 按批次、资产筛选最终输出 |

效果示意不使用当前项目地形，不采样高程，也不能直接导出 XML。样本中效果合适，不代表任意大小、凹形或带孔区域都会呈现相同分布。

## 参考范围与图例

有参考半径时，示例根据 **参考半径 × 实例缩放**绘制半透明圆；候选权重与随机缩放参与尺寸展示。没有可用尺寸的点保留普通角色符号。

范围圆不是精确树冠、碰撞边界或覆盖率；可以超出样本轮廓，不会自动删点、移动点或调整间距。参考高度也不会在此变成三维模型。

图例可以临时隐藏某类用途的示例点；**实心点位**开关隐藏参考圆，便于看中心点。这些只影响示例显示，既不关闭用途，也不筛选最终输出。要排除正式结果，请在搭配中关闭用途，或在项目[点位预览](./batches.md)里筛选资产。

已有方案优先使用保存的尺寸，新加植被使用当前资产信息。只修改资产库半径不会静默更新方案，应先[同步资产信息](../resources/mixes.md#同步资产信息)。

## 没有示例或示例更新失败

示例是策略包的可选能力。旧包没有声明时不会出现画布，更新客户端也不会自动给旧包补上样本。当前三个维护版本都已提供样本，见[内置策略](../strategies/overview.md)。

示例使用独立的小样本执行预算，超时或过密可能导致更新失败。可以重试或减少密度；示例失败本身不会禁止正式种植，也不等于正式长任务会按示例的时间上限结束。
