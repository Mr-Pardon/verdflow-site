# 输出 XML 与坐标偏移

<p class="lead">输出当前预览中保留的点位，不必为每一批单独交付。</p>

## 从预览进入输出

在预览中选择需要的批次和植被图例，再点击 **输出预览点位**。这一步保存需要提交的当前批次并打开输出面板，还没有开始高程采样。面板的批次、区域与点位计数对应当前保留结果。

确认计数和偏移后点击 **生成 XML**。系统按所选批次补齐缺少的高程，复用已有高程结果，最后按本次资产筛选合并生成一份 XML，不是拼接历史 XML 文件。排除某一批或某种植被，不会删除之前已经生成的历史 XML。

::: tip 高程按批次处理
首次采样针对所选批次保存的点集，不保证只采样本次勾选的资产点。因此，仅隐藏某种植被不一定能绕过该批次中的高程错误。整个批次不参与本次输出时才不会为它启动采样；修改偏移或筛选重新输出时，可复用已完成的高程。
:::

## XYZ 坐标偏移

偏移应用于本次生成的 XML，不改变保存的原始点位与高程数据。

| 输入 | 含义 |
| --- | --- |
| X | 输出坐标的 X 偏移 |
| Y | 输出坐标的 Y 偏移 |
| Z | 输出高程的偏移 |

同一批点位需要另一份偏移结果时，修改偏移并重新生成即可，不需要重新执行种植算法。返回预览再进入输出时，也应保留尚在使用的偏移设置。

::: warning 偏移不是坐标转换
米制投影与经纬度之间的转换、不同坐标空间的变换，应在上游完成。XYZ 平移不能代替它们。
:::

## 项目 XML 列表

成功生成的 XML 保留在项目内，可以另存为或手动删除。回到区域选择、继续种植或重新进入输出，不应清理已有文件。

生成时间、点位数量与文件大小帮助区分结果。文件多时可以滚动列表，不需要把全部输出挤在同一屏。

这是一份输出文件留档，不是可以完整恢复当时策略、选区和参数的项目快照。重要交付建议另存到明确命名的目录。

## 删除与另存为

删除前核对文件，确认后删除项目内该项输出。已经另存到其他位置的副本不属于这一操作的管理范围。

输出失败时先检查错误与高程数据，参见[常见问题](../reference/troubleshooting.md)。不要因为预览可见，就假定所有点位都已经具备有效高程。
