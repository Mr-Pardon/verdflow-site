# 多批次与点位预览

<p class="lead">一片地形不必只使用一种策略。逐批完成，再统一决定保留哪些点位。</p>

## 继续种植

生成点位进入预览后，点击 **继续种植**，保留本批结果并回到区域选择。已经种植的面仍可作为参照，但不再允许重复选取。

下一批可以使用不同策略、不同植被搭配和不同参数。这里保存的是种植批次，不是强制先为每批输出一份 XML。

## 按批次与植被筛选

预览侧栏先显示批次，展开后显示该批的植被资产图例。可以选择整个批次，也可以只保留其中某些植被。

图例按植被名称展示。筛选只影响当前预览与后续输出，不会因为取消勾选就永久删除已保存点位。

当前批次全部反选后，也可以输出其他已保留批次；当所有批次都没有保留点位时，不能生成一个有效种植输出。

注意“当前批次”与“已保存”不同：若当前批次全部反选后点击 **输出预览点位**，本次尚未保存的生成结果会被放弃，只提交其他保留批次。需要保留当前结果以后再用时，先重新勾选需要的点位并通过 **继续种植**保存，再从已保存批次中筛选输出。

## 重新种植某一批

1. 找到该批右侧的圆箭头按钮，悬停提示为 **重新种植这一批**。
2. 回到种植设置，调整策略、搭配或参数。
3. 生成新点位，回到预览核对效果。
4. 点击 **继续种植**或 **输出预览点位**提交新结果，替换对应批次；这一步不是另一个“确认替换”弹窗。

新结果提交前，原批次仍保留。新执行失败或取消时，不会先删除旧结果；在重新配置阶段返回预览，可以放弃此次替换。

删除批次则会释放对应区域，供后续重新选择。删除需要确认，不能当作临时隐藏使用。

## 大视角与细节视角

大视角主要显示区域关系，避免一次绘制所有点位。拉近后按视口加载并显示具体点位；未种植面仍然保留为空间参照。

读取大点位集需要时间。遇到加载失败先查看错误并重试，不要连续切换页面制造更多重复请求。

## 显示参考范围

植被配置中有参考半径，且本次点位分配保存了该信息时，可以显示透明范围圆。显示半径由 **参考半径 × 实际 XY 缩放** 得到。

范围圆是配置值的近似示意，不是实际模型包围盒或精确碰撞检测。没有半径信息的植被仍按普通点显示。

给资产补填半径后，已有搭配与旧点位不会自动回写。先同步搭配的资产信息；需要让新值进入点位结果时，再按新配置生成。

## 执行中离开页面

工作台支持长任务提示、取消与执行中重新进入。执行时显示持续计时，运行较久时给出非阻断提示；可主动取消，而不是达到固定时间就判定策略失败。

取消不保证逐指令立即结束，等待后台进入终态后再重新生成。离开或重新进入页面后，以项目任务状态判断执行是否完成。
