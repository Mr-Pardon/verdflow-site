# 参数、权重与缩放

## 常见数值的单位

| 数值 | 用户输入 | 含义 |
| --- | --- | --- |
| 候选权重 | 百分比，总值自动配平为 100 | 同一角色的相对分配概率 |
| 固定 / 范围缩放 | 百分比，如 80–120 | 模型原始尺寸的 0.8–1.2 倍 |
| 参考半径 | 米，如 2 | 100% 缩放时的水平参考半径 |
| 参考高度 | 米，如 8 | 100% 等比缩放时的竖向参考尺寸，不是海拔 |
| 间距 / 边界退让 | 米，以参数标注为准 | 算法生成点位时的距离约束 |
| 覆盖率 / 面积比例 | 百分比 | 空间算法的控制目标，不是实测模型覆盖保证 |
| 随机种子 | 整数 | 决定同一配置下的随机变化 |

数值范围以具体策略声明为准。草坪点景的主景出现概率使用 0–1，例如输入 0.75 表示 75%；不要把它与权重或缩放的百分比控件混淆。

## 权重为什么不是精确数量

权重控制概率。橡木 70%、榆树 30% 不代表生成 10 个点一定得到 7 个橡木和 3 个榆树。点位少时，随机分配的波动更明显。

调整一个候选后，面板会自动平衡其他候选的权重。不要为了凑总数反复手工输入小数。

## 缩放与真实边界

缩放会影响植被的真实大小，但策略通常不感知候选模型的精确形状。需要限制边界越界时，合理配置缩放、间距与退让，不要把点位在区域内等同于整个树冠在区域内。

参考范围圆也只是人为填写的近似尺度，不能代替真实几何检测。

## 按策略查看具体参数

| 策略版本 | 调整入口 |
| --- | --- |
| [层次生态群落 2.2.2](../strategies/community.md#当前可调参数) | 铺底覆盖、主景覆盖、两类间距与宏观斑块尺度 |
| [草坪点景组团 1.0.2](../strategies/lawn.md#当前可调参数) | 主体草坪间距、组团密度、主景概率与单区域组数上下限 |
| [通用行道树 2.0.2](../strategies/street-trees.md#当前能调整什么) | 当前没有面板公开的构图参数；可调整搭配、缩放、用途开关与种子 |

参数定义属于具体策略版本；不要因为另一个版本有同名参数，就默认它们有完全相同的含义。

## 参数为什么消失了

策略可以声明参数关联哪些用途。只要任一关联用途启用就显示，全部关闭时隐藏；全局参数始终显示。隐藏不会删除草稿或搭配预设中的值，重新启用时恢复。

例如层次生态群落关闭铺底后，不再显示铺底覆盖率与间距，但主景比例仍可调整。草坪点景的主景概率也影响周围点位，所以关闭中心主景后它仍可能显示。

## 把参数保存为方案

保存种植方案会同时保存完整公开参数，不再单独勾选。加载时按绑定策略的默认值与保存参数重新初始化；历史无参数方案使用默认效果，不继承上一套草稿。本次临时调整不会自动回写方案。

随机种子不进入方案。更新与另存操作见[保存方案与参数](../resources/mixes.md#保存方案与参数)。

## 怎么调整比较容易判断

支持样本的策略可以先打开[效果示意](../manual/effect-preview.md)，在固定小样本上比较参数；确认方向后再生成实际区域点位。示意图例只控制显示，不筛选最终输出。

先固定植被搭配与随机种子，只改变一项参数，比较效果。确定密度与比例后再更换种子，避免同时改变太多条件而不知道差异来自哪里。

面积很大时，先使用较大的间距做链路验证。角色数量上限仅在相应策略提供时可用，不是所有策略都有统一的上限参数。
