# 交换包参考

## 四种包，四种目的

| 格式 | 内容 | 不包含 |
| --- | --- | --- |
| `.vfs` | 策略清单、角色、参数、生成算法与可选用途图、参数样本 | 实际 DTS 三维模型 |
| `.vfa` | 资产目录、分类、植被信息与受管缩略图 | 模型安装文件、植被搭配 |
| `.vfp` | 某精确策略版本的种植方案：候选、开关、权重、缩放与公开参数；兼容历史无参数文件 | 策略算法、完整资产库、模型、随机种子；不保证携带缩略图 |
| 作者工具包 `.zip` | 模板、Skill 和创作说明 | 已完成且可直接执行的成果保证 |

这些格式不是数字签名认证。专用后缀让产品识别用途，校验只能检查已定义的结构与约束。

## 分享一套种植方式

至少提供对应 `.vfs` 和 `.vfp`，说明接收方需要的 DTS 模型资源。需要便于查找与再次编辑时，再提供 `.vfa`。

搭配保存自身的目标定位信息，不强制绑定某个资产库发布版本。资产包也没有为了每次编辑而建立不可变版本体系。

用途示意随策略包走，不是由应用根据策略名称临时补图。只给接收方旧版 `.vfs`，不会因为更新了客户端就自动得到新版图示。

带参数预设的 `.vfp` 仍绑定精确策略版本。参考半径与参考高度可随资产和搭配交换，不代表自动测量了模型或改变了策略算法。

当前界面保存方案会写入全部公开参数；旧文件未包含参数时按绑定策略的默认效果加载。多库候选保存各自的完整目标信息，来源库缺失不阻止完整方案使用，但目标 DTS 模型仍需准备好。

## 批量导入

策略库、资产库和种植方案支持批量文件选择与拖入导入。检查每个文件的结果；一组文件中出现失败，不代表其他文件一定也未导入。

导入策略包后，还要按来源和代码内容决定是否信任。不要把导入成功视为执行安全的证明。

## 查看包内容

交换包采用结构化容器与清单，不是加密资源。需要查看时对副本操作，使用支持 ZIP 容器的工具；不要直接修改唯一的交付包。

手工改变清单或代码后，应重新校验并导入测试。扩展名正确不等于包内容正确。

## 用户数据与项目不是交换包

`.vfa` / `.vfp` 适合交换特定资源，不是整个项目的完整备份。项目点位、输入文件和 XML 留档应通过[数据备份](./backup.md)保护。
