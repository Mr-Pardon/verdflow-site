# 数据备份与更新

## 需要保留两个位置

| 位置 | 主要内容 |
| --- | --- |
| `%LOCALAPPDATA%\VerdFlow` | Library、system-config、Logs、Electron 等用户数据 |
| 创建项目时选择的目录 | 项目状态、输入与运行产物、点位及保留的 XML |

软件解压目录不再承担用户数据根目录。更换便携包时，不应把“旧软件目录”和“全部用户数据”混为一谈。

## 备份步骤

1. 等待当前任务结束或明确取消，退出 Studio。
2. 复制完整用户数据目录到备份位置。
3. 复制需要保留的项目目录。
4. 对关键交付 XML 另外保存副本，并使用可识别的文件名。

可以额外导出 `.vfs`、`.vfa`、`.vfp`，用于独立交换与核查。但它们不能代替完整项目备份。

## 凭证

模型服务等 API 凭证由 Windows 系统凭证存储管理。普通文件夹备份不保证能迁移所有密钥，跨电脑使用时应重新配置与验证连接。

不要把凭证、完整日志中的敏感内容或私人路径放进公开 GitHub 仓库。

## 更新便携包

先备份，再将新版本解压到新的软件目录并启动。相同 Windows 用户下的软件会使用统一用户数据目录；仍应阅读版本说明，不能假定所有未来版本都无条件兼容旧项目。

更新前阅读目标版本的兼容说明；涉及项目或资源格式变化时，按对应迁移步骤操作，并保留升级前的备份。

## 删除与移出项目列表

删除有效 VerdFlow 项目会包含本地项目文件，应认真核对二次确认中的目标目录。

如果记录对应的目录不是当前可识别的 VerdFlow 项目，点击该卡片的删除入口时，确认框应显示 **移除项目记录？**，操作按钮为 **移除记录**。此时只清理列表记录，不删除原目录和文件；若看到 **删除整个项目？ / 永久删除**，应先取消并核对目标。

对文件身份不确定时，先备份并查看目录结构，不要尝试强制删除。
