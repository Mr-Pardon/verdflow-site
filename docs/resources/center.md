# Studio 内置资源中心

<p class="lead">在 Studio 里找一套可用的种植资源，看清它需要什么，再导入本地。</p>

## 1. 找到合适的资源

点击 Studio 侧栏左下角的 **资源中心**。按资产库、策略或种植方案筛选，也可以用名称、用途、作者或标签搜索。

| 想准备什么 | 看哪类资源 |
| --- | --- |
| 植物名称、缩略图和 DTS 模型名 | **资产库**（`.vfa`）；它记录模型信息，不安装模型 |
| 一种空间分布方法 | **策略**（`.vfs`）；注意它需要面还是开放折线 |
| 一套可以直接选用的设置 | **种植方案**（`.vfp`）；保存策略、植被搭配和公开参数 |

第一次使用，也可以先看[获取第一套资源](../guide/first-use.md#一键准备推荐资源)，在引导中批量导入，不必逐件挑选。

## 2. 查看版本和关联资源

打开卡片，阅读资源说明和**版本记录**，再用详情里的版本选择器核对要导入的版本。需要复用已有方案时，优先核对它要求的策略，而不是只看名称相不相同。

查看**关联资源**：如果提供了配套 PAK，按链接页面的获取和安装说明，在 DTS 中单独准备。Studio 不会随资产库或方案安装 PAK，也不会自动替换场景中的模型引用。

## 3. 确认导入，检查本地结果

1. 点击 **导入 VerdFlow**，检查确认窗口中将要导入的内容，再继续。
2. 导入种植方案时，如果缺少兼容策略，按提示补齐可用策略，或手动导入相应 `.vfs` 后重试。缺少来源资产库时，完整方案可以独立保存搭配；按需另行导入资产库，便于浏览和继续选材。无论是否导入来源库，DTS 场景仍须有相应模型。
3. 已导入的资源可通过 **已导入 · 查看本地**回到资源库。执行策略前，在**策略库**审阅来源并确认信任；下载与内容校验不会自动授予信任。

## 更新版本与手动导入

- **策略库提示有新版**：可以打开对应的资源版本详情。导入的新旧策略版本并存，新版需要单独信任；导入不改写已保存的方案或历史结果。加载方案时如何选用已安装版本，见[方案与策略版本兼容](./strategies.md#方案与策略版本兼容)。
- **本地已有资源**：先核对提示，再决定如何处理。尤其是资产库，同名或同 ID 不代表内容相同。本地修改不会被静默覆盖。
- **联网失败或版本没有应用内导入入口**：可以刷新重试，或通过 **网页版**获取可下载的包，再回 Studio [手动导入](../reference/packages.md#批量导入)。离线时可以继续使用已准备好的本地资源。

推荐资源只导入了一部分时，按[下载失败或校验失败](../reference/troubleshooting.md#推荐资源只导入了一部分)分别处理，已成功的资源无需重导。
