# 资产库与分类

<p class="lead">把可用植被整理成一个好查找、好选择的信息目录。</p>

## 资产库保存什么

资产库保存植被的显示名称、目标资源定位信息、分类、标签、缩略图、建议缩放，以及可选的参考半径和参考高度。当前 DTS 资产使用目标静态网格名称定位。

它不保存或安装实际的三维模型，也不保证目标 DTS 场景中存在对应资源。交给其他人使用时，需要同时说明场景资源准备条件。

## 新建与编辑

在资产库点击 **新建资产库**，填写名称并选择输出目标。界面使用目标选项，不需要手动理解或填写底层 Provider ID。

<Shot src="/media/studio-create-catalog.webp" alt="新建资产库弹窗中的名称、标识和 DTS 输出目标选项" caption="真实新建资产库界面，使用示例名称与标识" />

有多个 Catalog 时先选择要管理的库；进入后使用全幅管理页面。没有现成库时，可以从空库开始录入，不必先导入一个标准包。

## 添加植被

建议至少填写这两项：

- **植被名称**：用户看到的名称，便于列表与图例识别。
- **目标静态网格名称**：DTS 实际使用的资源名，应准确匹配目标场景。

例如显示名称可以是“橡木”，目标名称则保留场景中真正可用的网格名。不要让 Agent 根据中文植物名猜测一个并不存在的模型名。

## 分类与搜索

分类对应底层 Collection。一个植被可以属于多个分类，例如同时属于“乔木”和“行道树”。分类不是另外一套资产副本。

编辑和选择植被时，可以通过名称、ID 或标签搜索，再用分类筛选缩小范围。分类栏固定在列表顶部，滚动后仍可切换。

## 缩略图

选择适合识别植被的图片，建议使用正方形构图。界面以 1:1 包围盒显示，图片填满区域；没有图片时回退到植被占位图。

缩略图作为受管资源随 `.vfa` 交换，不应依赖另一台电脑上的绝对路径。准备对外分享时，确认图片拥有可分享的使用权。

## 参考半径

**参考半径**为可选值，单位是米，描述植被在 **100% 缩放时的水平影响范围半径**。

例如原尺寸的植被参考半径为 2 米，点位实际缩放为 120%，预览参考圆半径约为 2.4 米。它不代表植被高度，也不是自动测量的精确边界。

留空不会阻止种植。有数据时可支持范围预览；当前不承诺策略会根据半径自动调整所有间距或防止真实模型越界。

## 参考高度

**参考高度**从 `0.2.0` 起可以选填，单位是米，表示模型在 **100% 等比缩放时的竖向参考尺寸**。它与参考半径独立，不是地形海拔、采样高程或点位的 Z 坐标。

已知模型原始高度约为 8 米时，可以填 8；不知道时留空，不要从植物名称或缩略图猜测。填写的值应为有限正数，零不是“未知”。

当前参考高度只作为资产尺寸信息保存、交换和进入运行快照，不绘制三维高度柱，不自动推导间距，不改变策略、高程采样、缩放或 XML。它不会把树的根部抬高 8 米。

给资产补填高度后，已有植被搭配仍保留原有信息；需要主动同步资产信息才能更新。已经生成的批次和历史 XML 不会自动变化。

## 导入、导出与搭配同步

通用素材与项目临时素材可以分库维护。当前搭配支持跨兼容资产库选择，切换浏览库不会清空已选植被；无需为了种植先把目录合并。操作见[跨资产库选植被](./mixes.md#跨资产库选植被)。

使用 `.vfa` 导入或导出资产信息与缩略图。支持批量选择和拖入导入，结果应逐项查看；文件名相同不等于内容相同。

已有植被搭配保存独立资源信息。修改资产库不会悄悄改掉所有搭配，必要时在搭配中同步资产信息并审阅变化。删除 Catalog 也不等于删除 DTS 中的模型。
