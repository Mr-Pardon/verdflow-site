# 种植方案与植被搭配

<p class="lead">把种植方式、植被搭配和效果参数保存成一套方案，下次选好区域就能复用。</p>

## 从哪里开始

从侧栏的 **快捷种植 → 种植方案**进入。方案以卡片展示，可以搜索名称、植被或按策略筛选，点击卡片查看和编辑。

新建方案时先选策略及精确版本，再配置植被用途与效果。无需先创建项目。工作台和实时面板也提供两条入口：

| 入口 | 适合什么时候 | 操作 |
| --- | --- | --- |
| 预设方案 | 已有适合的配置 | 选择方案，确认选区后开始；需要时再调整方案 |
| 手动配置 | 第一次搭配或需要重新设计 | 选择种植方式、配置植被、调整效果，再生成 |

旧界面里的“植被搭配”库现在统一为 **种植方案**。植被搭配仍是方案内部的配置步骤；底层沿用 Profile 与 `.vfp`，不需要为了名称变化转换旧文件。

## 给每个用途配置植被

用途代表空间职责，不是指定树种。先看用途说明、推荐素材与静态构图示意，再为当前用途添加候选。支持多候选的用途可使用多种植物；标记为单种植被时按面板提示配置。

<Shot src="/media/strategy-community-ground.webp" alt="层次生态群落的铺底用途、静态构图示意与推荐植被" caption="用途组件与包内声明；静态示意解释空间关系，不是当前选区结果" />

在选择面板里通过资产库、分类与搜索查找植被，勾选候选并应用。分类、搜索只筛选浏览内容，不取消已选项。

| 设置 | 意义 |
| --- | --- |
| 权重 | 同一用途内选用某个植被的相对概率，自动配平为 100% |
| 缩放 | 资产默认、固定百分比或随机百分比范围 |
| 移除候选 | 从当前用途中去掉植被，不删除资产库记录 |
| 用途开关 | 不输出该用途的点位，保留候选和参数以便恢复 |

## 跨资产库选植被

`0.3.1` 支持在同一搭配中混用多个兼容资产库。例如先从通用库选乔木，再切到项目临时库选灌木，不需要先合并两个库。

切换资产库只更换浏览区，已选候选、权重、缩放、用途开关与参考尺寸继续保留。已选植被会显示来源；不同库里相同的资产 ID 不会互相覆盖。

一次搭配须属于同一输出目标及资源提供方式，不支持混用不兼容目标。同一个真实模型来自不同库时不会自动合并，权重与缩放分别保留；出现重复模型提示时检查是否为有意配置。

来源库被删除后，完整方案仍保存自己的资源信息。缩略图可能变成占位图，但不因此失去执行能力；DTS 里的真实模型仍须存在。

## 关闭用途或整个分类

可以关闭单个用途，也可以用分类开关一起切换该分类下的用途。至少保留一个启用用途，并为所有启用用途配置有效候选。

关闭后该用途不会进入最终输出；其他用途是否重新分布由策略版本决定。例如层次生态群落关闭铺底后，主景覆盖改以整个区域为基准；草坪点景组团关闭中心主景不会重排周边灌木。

仅与关闭用途关联的参数会隐藏，原值与候选仍保留；重新启用后恢复。具体规则见[内置策略](../strategies/overview.md)。

## 缩放规则

- **资产默认**：采用所选资产建议的缩放规则。
- **固定**：100% 保持原始尺寸，80% 缩小为 0.8 倍。
- **随机范围**：例如 80–120%，为每个实例分配范围内的缩放。

规则保存于方案中，不依赖每次执行时临时读取资产库。权重表示分配概率，不是精确数量上限。

## 保存方案与参数

当前保存操作会一并保存 **精确策略版本、植被候选、用途开关、权重、缩放和完整公开参数值**，不再提供“同时保存参数”的可选勾选框。

1. 完成搭配，并调整公开效果参数。
2. 点击保存种植方案。
3. 选择更新当前方案或另存为新方案，确认名称后保存。

<Shot src="/media/live-save-plan-v031.webp" alt="实时种植方案保存窗口，支持更新当前方案和另存为新方案" caption="0.3.1 真实组件与隔离演示数据；保存包含当前公开参数" compact />

| 操作 | 结果 |
| --- | --- |
| 加载已有方案 | 使用绑定版本的默认参数加方案保存值，重新初始化草稿 |
| 加载历史无参数的 Profile | 使用绑定版本默认效果，不继承上一套草稿，也不改写旧文件 |
| 本次微调或仅本次应用 | 只改变当前执行草稿，不自动更新保存的方案 |
| 更新当前方案 | 覆盖该方案的搭配与公开参数 |
| 另存为新方案 | 建立独立副本，原方案不变 |

随机种子、选区、高程、点位、XML 和输出偏移不在方案中。重新种植历史批次仍按该批冻结的输入恢复，不悄悄使用方案后来修改的参数。

## 同步资产信息

资产名称、参考半径或参考高度变化后，可以主动同步并审阅。多库方案按各候选的来源分别检查，来源缺失时保留已保存信息；同步不会清除方案参数，也不会自动改写资源定位。

修改方案不重写已生成批次或历史 XML。想使用新尺寸参与预览和输出，应同步配置并重新生成相关结果。

## 导入与导出

`.vfp` 保存一套方案，不包含策略算法、完整资产库、实际三维模型，也不保证携带来源缩略图。支持批量选择与拖入导入。

分享时同时说明所需的精确 `.vfs` 版本和 DTS 资源条件。`.vfa` 可用于补充浏览与编辑素材，但不是完整方案执行的强制依赖。
