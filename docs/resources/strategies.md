# 策略库与信任

<p class="lead">选择一种空间组织方式，再用搭配和参数把它变成自己的效果。</p>

## 常用策略的用途

| 策略 | 适合的关系 | 注意 |
| --- | --- | --- |
| [层次生态群落](../strategies/community.md) | 铺底与主景形成连续疏密 | 2.2.2；关闭铺底时主景以整个区域为覆盖基准 |
| [草坪点景组团](../strategies/lawn.md) | 连续草坪与内部点景组团 | 1.0.2；主体间距可调，退距与收边间距是算法常量 |
| [通用行道树](../strategies/street-trees.md) | 按宽度组织灌木排与沿线乔木 | 2.1.1；需要狭长绿带面 |
| [沿线树池种植](../strategies/path-planters.md) | 沿手绘路径等距布置植被与可选树池 | 1.0.0；只用于 DTS 实时开放折线 |

这些名称不代表必须使用特定树种。角色与具体植被分开设计，详见[核心概念](../manual/concepts.md)。

侧栏的 **常用策略**可展开查看详细用途、包内示意、参数与调节建议。策略包可从 [Studio 资源中心](./center.md)获取，导入后按需信任。先看[如何选择策略](../strategies/overview.md)，不必为了理解构图先读算法源码。

## 用途说明与构图示意

新维护包带有植被用途分组、推荐素材和静态位置示意，Studio 与实时搭配面板读取同一份资料。它们随 `.vfs` 分发，不会凭策略名称自动补到旧包上。

图示帮助理解关系，不是当前选区的生成结果，也不会根据所选资产的尺寸自动改变。没有展示资料的旧包或第三方策略仍可正常执行，前提是策略本身有效且已信任。

## 导入与导出

支持样本的策略还可以在配置时运行[动态效果示意](../manual/effect-preview.md)。它使用原算法和固定合成边界，与这里的静态用途图不同；旧包不会因客户端更新自动得到样本。

策略包使用 `.vfs`。可通过文件选择或拖入导入，也可以批量选择。导入后查看名称、版本、描述、角色与参数。

还没有资源时，可以[一键导入推荐资源](../guide/first-use.md#一键准备推荐资源)。推荐导入同样不会自动确认策略信任。

策略库支持导出策略包，方便交换与审阅。创作模板与 Skill 则从作者工具包入口导出，外层是易打开查看的 ZIP。

## 为什么需要确认信任

策略包含可执行算法代码。导入成功仅表示包满足读取条件，不能代替代码来源审查。

确认信任针对具体包内容。新版本或改变后的包不应无条件继承旧包的信任。工作台选择未信任策略时，也可以通过二次确认完成信任。

策略库支持一次确认批量信任本次明确选定的包集合，不会自动信任未来版本；主动撤销过的包不会默认被批量重新信任。

::: warning 信任不是认证
确认信任不代表安全认证，也不是对任意恶意代码的完整隔离保证。仅运行经过审阅且来源可信的策略包。
:::

## 同一策略的不同版本

工作台按策略分组显示卡片，再切换版本，而不是每个版本放一张重复卡片。版本决定角色、参数和算法行为；加载已有方案时，界面会显示当前实际使用的版本。

更新策略后，不要只核对显示名称。角色键、算法行为和参数语义都可能变化，应先测试一小片区域并检查搭配。

## 方案与策略版本兼容

方案保留保存时的策略版本作为**保存基线**。加载时，VerdFlow 从本机**已安装、已信任且通过角色与参数校验**的策略中，优先选择同一策略 ID、同一主版本的最新兼容正式版；没有可用新版时仍可使用符合条件的原版。

例如，保存于 `2.2.2` 的方案可以使用兼容的 `2.2.3` 或 `2.3.0`，但不会自动改用 `2.2.1` 或 `3.0.0`。这些版本号仅用于说明规则。

| 情况 | 处理方式 |
| --- | --- |
| 同主版本的兼容新版 | 安装、信任并通过校验后可以使用 |
| 新版未安装或未信任 | 不自动下载，也不继承旧包信任 |
| 角色或参数不符合约束 | 显示不可用原因，不丢弃字段或强行截断数值 |
| `0.x`、预发布或非规范历史版本 | 仅按原精确版本匹配 |
| 仅构建标记不同，或同一版本号的包内容不同 | 不作为自动升级的依据，也不能冒充原包 |

兼容新增的可选用途在旧方案中默认关闭；新增公开参数使用实际策略的兼容默认值。仅查看或加载方案不会改写保存基线，明确保存或另存时才会记录所用配置。

::: tip 兼容复用与精确复现不同
兼容承诺不保证逐点相同。任务提交后会固定实际策略版本与包内容、方案快照、参数和随机种子；之后更新策略或方案，不会改写已有批次。需要精确复现时，应保留原策略包及对应运行输入，而不只记录版本号。
:::

## 调整与创作的边界

策略已经公开的参数、随机种子、植被候选和缩放可以在种植面板调整；未公开构图参数的策略不会凭空出现滑块。保存种植方案时会包含全部公开参数，随机种子仍独立设置。

要改变空间算法、增加角色或引入新参数，则进入 [VFS Author](../authoring/strategy.md) 作者流程。

当前不要求在产品内训练策略，也没有内置完整策略编辑器。
