# 如何选择常用策略

<p class="lead">先看手头是面还是路径，再决定怎么分布、用哪些植被。</p>

## 按目标效果选择

| 目标效果 | 策略 | 当前维护版本 |
| --- | --- | --- |
| 低矮植被承接较高植被，形成连续、自然的疏密变化 | [层次生态群落](./community.md) | 2.2.2 |
| 以连续草坪为主体，在内部点缀少量完整植物组团 | [草坪点景组团](./lawn.md) | 1.0.2 |
| 狭长绿带面中按宽度组织灌木排，并沿中心路径布置乔木 | [通用行道树](./street-trees.md) | 2.1.1 |
| 在 DTS 实时面板画一条开放折线，等距排布植被与可选树池 | [沿线树池种植](./path-planters.md) | 1.0.0 |

这些策略可从 [Studio 资源中心](../resources/center.md)获取；开始前确认已导入并信任要用的版本。前三项接收区域面；沿线树池种植只接收开放折线，不用于项目工作台的面选区。参数与行为以实际选用的策略包版本为准。

## 不必把整片地形交给同一个策略

宽阔面状绿地可以使用群落或草坪点景，狭长绿带使用行道树。在项目路线中按区域分批生成，最后在[点位预览](../manual/batches.md)中统一筛选与输出。

策略不是具体树种。层次生态群落的主景可以使用乔木，也可以使用适合承担主要体量的灌木；搭配建议只是帮助选材，不是物种白名单。

## 先看植被用途，再选素材

配置植被搭配时，界面会把策略角色展示为 **植被用途**。可以查看用途分组、推荐植被和构图示意，再为当前用途选择素材。

- 用途名称来自策略包，换版本后名称和规则可能变化。
- 同一用途可以由不同植被承担；是否支持多候选以策略声明和面板提示为准。
- 推荐植被是选材方向，不会自动选择素材，也不校验场景是否已经安装模型。
- 构图示意来自策略包，说明位置关系；它不是当前选区的真实预览、尺寸图或算法效果评测。

## 一次只调整一类因素

1. 先用默认参数与小范围区域，完成一次完整预览。
2. 固定植被搭配和随机种子，调整间距、覆盖率或组团数量。
3. 确认空间组织后，再调整素材缩放和候选权重。
4. 最后更换随机种子，探索同一规则下的不同结果。

上表各版本都提供固定的小样本，可以先打开[效果示意](../manual/effect-preview.md)比较参数变化。效果合适时，将植被与完整公开参数[保存为种植方案](../resources/mixes.md#保存方案与参数)；随机种子不属于方案。

## 更新包，不等于升级所有项目

新包需要重新导入，并针对其具体内容确认信任。方案可使用通过校验的同主版本新版，加载不会改写保存基线；已有批次与 XML 不会重新计算。详见[版本兼容规则](../resources/strategies.md#方案与策略版本兼容)。

层次生态群落 `2.2.2` 优化密度场计算，少量边缘点可能与旧版不同。草坪点景组团 `1.0.2` 加入参数样本；通用行道树 `2.1.1` 开放五项构图参数。可在[内置资源中心](../resources/center.md)查看包的完整版本记录。
