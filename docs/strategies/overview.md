# 如何选择内置策略

<p class="lead">先决定空间关系，再决定用哪些植被。三个策略对应三种不同的组织方式。</p>

## 按你想要的效果选择

| 你的目标 | 策略 | 当前维护版本 |
| --- | --- | --- |
| 低矮植被承接较高植被，形成连续、自然的疏密变化 | [层次生态群落](./community.md) | 2.2.2 |
| 以连续草坪为主体，在内部点缀少量完整植物组团 | [草坪点景组团](./lawn.md) | 1.0.2 |
| 狭长绿带中按宽度组织灌木排，并沿中心路径布置乔木 | [通用行道树](./street-trees.md) | 2.0.2 |

本节只详细介绍这三个维护策略，不包含通用自然聚落。版本已于 2026-10-20 对照产品仓库 `0.3.1` 源码基线核对；实际执行以导入的精确包为准。

## 不必把整片地形交给同一个策略

宽阔面状绿地可以使用群落或草坪点景，狭长绿带使用行道树。在项目路线中按区域分批生成，最后在[点位预览](../manual/batches.md)中统一筛选与输出。

策略不是具体树种。层次生态群落的主景可以使用乔木，也可以使用适合承担主要体量的灌木；搭配建议只是帮助选材，不是物种白名单。

## 先看植被用途，再选素材

配置植被搭配时，界面会把策略角色展示为 **植被用途**。可以查看用途分组、推荐植被和构图示意，再为当前用途选择素材。

- 用途名称来自策略包，换版本后名称和规则可能变化。
- 同一用途可以由不同植被承担；是否支持多候选以策略声明和面板提示为准。
- 推荐植被是选材方向，不会自动选择素材，也不校验场景是否已经安装模型。
- 构图示意来自策略包，说明位置关系；它不是当前选区的真实预览、尺寸图或算法效果评测。

## 一次只调整一类因素

1. 先用默认参数与小范围区域，完成一次完整预览。
2. 固定植被搭配和随机种子，调整间距、覆盖率或组团数量。
3. 确认空间组织后，再调整素材缩放和候选权重。
4. 最后更换随机种子，探索同一规则下的不同结果。

当前三个版本都提供固定的小样本，可以先打开[效果示意](../manual/effect-preview.md)比较参数变化。效果合适时，将植被与完整公开参数[保存为种植方案](../resources/mixes.md#保存方案与参数)；随机种子不属于方案。

## 更新包，不等于升级所有项目

新包需要重新导入，并针对其具体内容确认信任。植被搭配绑定精确策略版本，旧版本的搭配不会自动迁移；已有批次与 XML 也不会被重新计算。

层次生态群落 `2.2.2` 沿用 2.2.0 的用途开关规则，并优化密度场计算；少量边缘点可能与旧版不同。草坪点景组团 `1.0.2` 与通用行道树 `2.0.2` 新增参数样本，空间算法沿用原基线，但仍需单独导入与信任。
