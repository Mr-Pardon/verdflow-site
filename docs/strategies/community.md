# 层次生态群落

<p class="lead">低矮植被铺底，主景植被在其中形成体量与疏密；也可以关闭铺底，让主景独立分布。</p>

## 适合哪些区域

适合普通面状绿地、生态种植区，以及希望植被自然成片、密疏连续变化的区域。不以规则行列或独立圆形小岛为目标，也不用于道路中心线种植。

两类植被共享一张宏观密度纹理，再通过各自的微观扰动形成细节。看起来是同一个群落中的上下层关系，而不是两套互不相关的随机散点。

## 两项植被用途

| 用途 | 空间职责 | 可考虑的素材 |
| --- | --- | --- |
| 铺底植被 | 形成较广的低矮覆盖层，承接主景 | 花草、地被、矮灌木 |
| 主景植被 | 形成主要体量与连续疏密变化 | 乔木、较高灌木 |

两项用途都支持多个候选植被，按权重分配。优先在同一用途中选择尺度相近、可以互相替代的素材；不用为橡木与榆树分别建立算法角色。

## 覆盖比例如何理解

**铺底与主景都启用时**，先按地表支撑覆盖率确定铺底范围，再在其高值核心中分布主景。主景覆盖比例以铺底范围为基准。

默认地表支撑覆盖率是 **85%**，主景覆盖比例是 **55%**。这描述两个空间支撑范围的关系，不等于最终模型树冠严格覆盖整个区域的 46.75%，也不等于点位数量占比。

**关闭铺底时**，主景覆盖比例改为以整个区域为基准。此时不再让关闭的铺底范围限制主景，主景可能重新分布。

::: warning 2.2.2 的角色开关不是简单隐藏
关闭铺底后，不能假定主景点位与双角色结果完全相同。固定区域、版本、参数、种子和开关状态时仍可复现，但不同开关状态对应不同构图。
:::

关闭主景、只保留铺底，则得到低矮覆盖层。至少保留一个启用用途，并为其配置有效植被。

## 当前可调参数

| 参数 | 默认值 | 范围 | 作用 |
| --- | --- | --- | --- |
| 地表支撑覆盖率 | 85% | 5–98% | 铺底允许分布的区域比例 |
| 主景覆盖比例 | 55% | 1–100% | 主景范围相对铺底或整个区域的比例 |
| 地表植被间距 | 3.4 米 | 0.5–12 米 | 铺底点位的基础疏密 |
| 主景植被间距 | 11 米 | 2–40 米 | 主景点位的基础疏密 |
| 宏观斑块尺度（高级） | 48 米 | 10–200 米 | 连续密度变化的空间尺度 |

默认随机种子为 `17`。关闭某项用途后，只与它关联的参数会隐藏，但原值仍保存在草稿和参数预设中；重新启用后恢复。宏观斑块尺度始终可调。

## 怎样调整更容易看出效果

当前包提供固定的“生态绿地”样本。在工作台的 **效果与预览**或实时面板的 **效果示意**中，先比较间距与覆盖变化；样本边界和种子固定，不等于当前选区的最终结果。见[效果示意](../manual/effect-preview.md)。

| 想改变什么 | 先调整 |
| --- | --- |
| 铺底更密，但覆盖范围不变 | 减小地表植被间距 |
| 铺底留下更多空白 | 降低地表支撑覆盖率 |
| 主景出现的范围更大 | 提高主景覆盖比例 |
| 主景范围不变，但树木更疏 | 增大主景植被间距 |
| 疏密斑块更大、更连贯 | 增大宏观斑块尺度 |
| 保持规则，换一种分布 | 重新选择随机种子 |

先调整间距，再调整覆盖关系，最后调整斑块尺度。一次改变太多参数，不容易判断是哪一项造成了差异。

## 选材与边界

间距控制点位中心，而不是模型之间的精确净距。较大树冠、较高缩放或差异很大的候选素材，都可能让视觉密度与点位密度不同。

可以为资产填写[参考半径与参考高度](../resources/assets.md)，帮助记录尺度。当前算法不会因此自动测量模型或按实际树冠防止相交。

## 升级旧搭配

`2.2.1` 增加了参数示例；`2.2.2` 优化密度场计算并调整覆盖阈值的统计预算，可能改变少量支撑区边缘点，不承诺与旧包逐点相同。两类用途关系、公开参数和旋转规则保持不变。

本文对应 `layered_ecological_community@2.2.2`。旧版的“地表基质 / 主景结构”在当前界面表达为“铺底植被 / 主景植被”，角色键仍分别是 `groundcover_matrix` 与 `focal_structure`。

即使角色键相同，搭配仍绑定精确版本。请导入并信任新包，为 `2.2.2` 建立搭配，先用小范围检查单角色与双角色效果；不要覆盖旧项目的冻结结果。
