# 草坪点景组团

<p class="lead">让草坪形成连续背景，再在区域内部放入少量主次清楚的植物组团。</p>

## 适合哪些区域

适合以草坪为主体，需要乔木、灌木和小型植被局部点景的面状绿地。与层次生态群落不同，它更强调连续草坪与一个个完整组团，而不是大范围连续主景斑块。

算法会避开边界和孔洞，为组团寻找可容纳的内部空间。无法安全容纳完整组团的小面或窄面，会退回草坪层，不强行塞入残缺点景。

## 五项用途，分成两组

| 分组 | 用途 | 空间职责与选材方向 |
| --- | --- | --- |
| 草坪覆盖 | 主体草坪 | 连续铺设内部；草坪块或低矮地被 |
| 草坪覆盖 | 收边草坪 | 更密、更小尺度地补齐边缘；小型草坪块或地被 |
| 点景组团 | 中心主景 | 组团中央的高大重点；乔木、棕榈或高大观赏植物 |
| 点景组团 | 组团灌木 | 围绕主景形成紧凑体量；球形或低矮灌木 |
| 点景组团 | 外围点缀 | 在组团外缘空隙中柔化边界；草花、小型观赏草或小灌木 |

五项用途都支持多个候选并按权重分配。推荐只是空间尺度与构图方向，不限制必须使用某一种植物。

### 草坪覆盖

<Shot src="/media/strategy-lawn-coverage.webp" alt="草坪覆盖用途示意，主体草坪位于内部，较小收边草坪分布在外缘" caption="策略 1.0.2 包内声明，由真实用途组件渲染；不是当前区域的尺寸或覆盖预测" />

主体草坪按带轻微扰动的错列网格分布，固定向内退让 **0.5 米**。收边草坪使用 **0.5 米**中心间距，覆盖距外边界或孔洞边界不足 **0.5 米**的边缘带。

这两个 0.5 米是当前算法常量，不是面板里的独立参数。收边可以沿用主体草坪素材，但通常要单独调小缩放，否则更密的点位容易叠成过厚的边缘。

### 点景组团

<Shot src="/media/strategy-lawn-feature.webp" alt="点景组团用途示意，中心主景周围分布灌木，外围空隙布置小型点缀" caption="突出中心主景用途，周边灌木与外围点缀作为构图参照" />

一个完整组团通常包含 **零至一株中心主景、2–4 株组团灌木和 2–3 株外围点缀**。组团整体可以旋转，内部也有小幅变化，不是完全相同的复制模板。

算法根据区域面积与可用内部空间推导组数，再做均衡分布；不是把所有组团都堆在几何中心。较窄、凹形或带孔区域仍需要先检查实际可容纳空间。

## 当前可调参数

`1.0.2` 增加“弧形花坛”参数样本，空间算法沿用原基线。可以在[效果示意](../manual/effect-preview.md)里比较草坪间距、组团密度和主景概率；样本并不是当前项目区域。

| 参数 | 默认值 | 范围 | 作用 |
| --- | --- | --- | --- |
| 主体草坪间距 | 1.2 米 | 0.5–4 米 | 控制内部草坪点位密度，不改变收边间距 |
| 点景组团密度 | 3 | 0–4 | 相对密度控制；不是每平方米的固定组数 |
| 主景植物出现概率 | 0.75 | 0–1 | 组团包含中央高大植物的概率 |
| 最少点景组数（高级） | 0 | 0–50 | 每个独立区域的组数下限；0 表示不约束 |
| 最多点景组数（高级） | 0 | 0–50 | 每个独立区域的组数上限；0 表示不约束 |

默认随机种子为 `17`。出现概率 **0.75 相当于 75%**，但该策略的参数输入范围是 0–1，不要在此输入 75；这与候选权重、素材缩放的百分比输入不同。

## 三个容易混淆的设置

### 密度与数量上限

密度先影响算法推导的自然组数，数量上下限再按每个区域约束，不按整个 RegionSet 汇总。

密度设为 **0** 时，只生成草坪，即使设置了最少组数也不会强行生成点景。几何无法容纳足够组团时，最少组数是期望，不保证突破空间安全要求。

### 降低出现概率与关闭中心主景

降低出现概率会让算法生成更多无主景组团，灌木会向中心收拢，外围点缀的组织尺度也随之改变。

**关闭中心主景用途则只排除主景点位，不重新排列周边植被。** 两者不是同一个操作。因此，中心主景关闭后，出现概率仍可能影响保留的灌木与点缀，不会必然隐藏。

### 草坪点位密度与真实铺满

1.2 米间距是否能连续铺满，取决于实际草坪模型的尺寸与缩放。模型较小时可能仍有缝隙；缩放较大时可能越过边界。

策略没有自动读取真实模型边界。请固定素材缩放，先检查小范围的内部覆盖与收边效果，再扩大区域。

## 推荐调整顺序

1. 先把点景密度设为 0，只检查主体草坪和收边的缩放与间距。
2. 恢复点景密度，配置尺度协调的中心主景、灌木和外围点缀。
3. 调整组团密度；必要时用单区域组数上限控制数量。
4. 再比较主景出现概率与角色开关，最后更换随机种子。

角色全部关闭会阻止生成；至少保留一项有效用途。关闭全部点景用途后，只剩草坪层；关闭两项草坪用途后，可单独使用已配置的点景层。
