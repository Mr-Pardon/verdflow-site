# 沿线树池种植

<p class="lead">画一条线，沿线按间距布置树木或灌木；需要树池时，把它与植被放在同一位置。</p>

## 什么时候使用

适合人行道、道路侧边等**位置由绘制路径确定**的线性布局。在 [DTS 实时种植](../workflows/live.md#沿线种植-绘制开放折线)中使用，输入是开放折线，不是闭合种植面。若已有狭长绿带面、希望策略按宽度自动组织灌木排，则使用[通用行道树](./street-trees.md)。

## 两个用途怎么搭配

| 用途 | 布置方式 |
| --- | --- |
| 植被 | 乔木或灌木沿路径等距放置，水平朝向随种子随机变化 |
| 树池 | 可选，与植被共用布置位置；模型本地 +Y 轴沿路径切线对齐，通常用固定缩放 |

两个用途独立选材和设置缩放。没有合适树池模型时，可不配置树池；不必用另一种植物顶替。使用树池时，先在小范围核对模型的本地朝向和与树木的比例。

## 三项可调参数

| 参数 | 默认值 | 调整后发生什么 |
| --- | --- | --- |
| 沿线间距 | 8 米 | 沿整条路径累计计距，转角不会重新开始计数 |
| 起点留距 | 0 米 | 从绘制的起点预留一段距离，终点不强行补齐 |
| 转角圆滑半径 | 0 米 | 0 保留折角；增大时点位沿转角过渡，实际半径受相邻线段长度限制 |

可在**效果示意**里先看预设样本，再用一小段实际路径检查。起点方向以绘制顺序为准。

本页对应 `path_paired_placement@1.0.0`。在 [Studio 资源中心](../resources/center.md)搜索「沿线树池种植」，导入后到[策略库](../resources/strategies.md)确认信任；策略包不包含 DTS 模型或 PAK。
