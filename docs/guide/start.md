# 选择你的上手路线

<p class="lead">不必先理解整套系统。找到你手边的数据，从一小片绿地开始。</p>

<RouteChooser />

## 第一次，先做小范围

选择一个轮廓清楚的小区域，优先使用已有种植方案完成一次预览。确认坐标、高程和目标植被都正确后，再扩大范围。没有方案时再选择手动配置。

开始前准备三件事：可用的区域数据、至少一个已信任的策略，以及目标场景中确实存在的植被资源。还没有软件？先看[安装与准备](./install.md)。

## 你会做的三个决定

| 决定 | 你在选择什么 | 例子 |
| --- | --- | --- |
| 种植方式 | 植被的空间组织关系 | 群落、草坪点景、行道树 |
| 植被搭配 | 由哪些具体植被承担空间角色 | 主景用橡木或榆树，地表用低矮灌木 |
| 效果参数 | 这一次的疏密、比例和随机变化 | 调整间距，更换随机种子 |

种植方案把这三项保存起来；使用预设方案时不必每次重新设置。手动配置或调整方案时，可以在[效果示意](../manual/effect-preview.md)里比较参数，再生成真实区域点位。随机种子仍单独设置。

## 如何选择

- 已经在 DTS 中打开地形，想直接看到种植结果：选 **DTS 实时种植**。
- 手里有 FBX，想按绿地材质提取区域：选 **FBX 模型种植**。
- 已有 GIS 面数据和 GeoTIFF 高程：选 **地理空间种植**。

::: tip 数据还没准备好？
可以先整理[资产库](../resources/assets.md)和[种植方案](../resources/mixes.md)。创建方案不需要先建立一个种植项目。
:::

## 当前适用范围

本指南适用于 **VerdFlow 1.0.0**，运行平台为 Windows x64，场景输出目标为 DTS。Blender 在 FBX 路线中承担模型处理和采样职责。

客户端与策略包分别管理版本。导入资源时核对策略 ID、版本及方案依赖，参见[更新说明](../updates.md)与[策略库](../resources/strategies.md)。
