# 快速开始

<p class="lead">装好 Studio，准备一套种植资源，再从一小片绿地开始。</p>

## 1. 安装并检查环境 {#install}

下载 Windows x64 便携版，完整解压后启动 VerdFlow Studio，确认顶栏显示本地服务正常。已有 DTS 场景、FBX、区域面或影像，需要准备的外部工具各不相同，不必全部配置。

**[查看安装与准备](./install.md)**

## 2. 准备第一套种植资源 {#resources}

在首次使用引导里**一键导入推荐资源**，审阅来源后信任要用的策略。已经跳过引导也可以在设置里重新打开，或直接从 Studio 内置资源中心挑选。

**[获取第一套资源](./first-use.md)**

资产库不包含 DTS 三维模型；需要配套 PAK 时，按对应资产详情单独准备。

## 3. 选择种植路线 {#routes}

需要直接写入已打开的 DTS 场景时，选择**实时种植**。需要保存项目、分批种植或输出 XML 时，选择 **DTS 项目工作台**，再按已有文件选择输入。三条项目路线先各自准备区域，再接续同一份[工作台种植流程](../workflows/workbench.md)。

## 自定义种植与创作

有合适的方案就直接用。想换植被、整理自己的素材库，或者现有策略不够用，可以从需要改变的部分入手：

- **用现有策略，换一套植被**：在种植时选择**手动配置**。先看[三个核心概念](../manual/concepts.md)，再从[常用策略](../strategies/overview.md)选一种分布方式，配上自己的植被。
- **现有策略不够用**：用 [VFS Author](../authoring/strategy.md)定义植被在空间里如何分布、有哪些用途，以及哪些参数可以调整。
- **有自己的植被资料**：用 [VFA Author](../authoring/assets.md)整理名称、分类和目标模型信息，做成可导入的资产库。

想了解这些能力如何配合，见[创作与扩展](../authoring/overview.md)。
