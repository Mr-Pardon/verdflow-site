# 获取第一套资源

<p class="lead">第一次可以一键导入。只需要个别资源时去资源中心，已有自己的资源也可以直接导入。</p>

## 一键准备推荐资源

首次启动时，跟随引导进入 **准备第一套种植资源**，点击 **一键导入推荐资源**：

1. 查看推荐清单中的名称、类型、版本和大小；需要了解配套模型时打开资源详情。
2. 点击 **全部导入**，等待下载、校验与本地导入。
3. 检查每项的结果。已导入和已存在的资源无需重做；若有[下载或校验失败](../reference/troubleshooting.md#推荐资源只导入了一部分)，按原因处理后只重试未完成项。
4. 回到策略库，审阅来源并确认信任。多个包都已核对时，也可以用 **批量信任**，先检查确认窗口列出的包与版本。曾撤销信任的策略不会被批量重新信任。

<Shot src="/media/studio-recommended-resource-import.webp" :width="1912" :height="1002" alt="首次引导中的准备推荐资源窗口，显示导入清单和全部导入按钮" caption="一键导入先展示本次清单，确认后才开始下载和导入。" />

如果跳过或暂停了引导，到 **设置 → 产品引导**点击 **查看引导**或**继续引导**即可重新打开。不需要重新安装 Studio。

推荐清单会独立更新。**导入不等于信任**，也不会安装 DTS 模型或 PAK；需要模型时，按资源详情单独准备。

导入过程中可以取消；已经完成的资源会保留，当前本地导入步骤可能先完成再停止。相同内容会复用，资产库内容冲突时不会直接覆盖，请按结果提示处理。没有网络时，仍可使用[本地资源包导入](../reference/packages.md#批量导入)。

## 从资源中心按需挑选

只需要一套方案、一个资产库或特定版本的策略时，点击 Studio 侧栏左下角的 **资源中心**。在详情里查看版本和依赖后，点击 **导入 VerdFlow**。完整步骤见 [Studio 内置资源中心](../resources/center.md)。

<Shot src="/media/studio-resource-center.webp" :width="1685" :height="935" alt="Studio 资源中心按资产库、种植策略和种植方案分类浏览" caption="资源中心可以按类型筛选，打开卡片查看版本和依赖。" />

## 导入自己的资源

已有 `.vfa`、`.vfs` 或 `.vfp` 包时，可以[手动导入](../reference/packages.md#批量导入)，不用先跑引导。想自定义植被分布，用 [VFS Author](../authoring/strategy.md)制作策略包；想整理自己的植被资料，用 [VFA Author](../authoring/assets.md)制作资产包。完成后再把包导入 Studio。

这些是可选的创作方式。只想用现成方案，不需要安装作者工具包，详情见[创作与扩展](../authoring/overview.md)。
