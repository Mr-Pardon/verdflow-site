# 更新说明

<p class="lead">查看影响操作的版本变化，以及对应的指南和升级方式。</p>

## 1.3.0

- **拾取绿地**：在 DTS 场景中选择独立的绿地构件，可提取完整的可见轮廓，或绘制范围只提取其中一部分。若绿地与道路合为同一构件，道路也可能被提取。见[绿地构件提取](./workflows/live.md#pick-green-space)。
- **场景笔刷**：直接刷选或刷除多个种植选区，刷除只改变勾选状态，不删除选区。
- **工作台区域预览**：密集画幅先显示概览，拉近后恢复边界细节。显示方式不改变实际种植几何。

版本说明及便携包见 [GitHub Releases](https://github.com/Mr-Pardon/VerdFlow/releases)。

## 1.2.1

- **实时 SHP 导入**：改为分批加载选区，保留原始边界与孔洞，不再沿用旧版的文件大小、累计顶点数与草稿总量限制。
- **策略库与种植方案**：策略详情可浏览构图和用途示意并试调参数；方案详情和编辑可查看植被搭配与效果示意。

完整变更见 [1.2.1 发布说明](https://github.com/Mr-Pardon/VerdFlow/releases/tag/v1.2.1)。

## 1.2.0

- **从影像识别绿地**：在项目工作台选择 RGB 影像与高程，完成本地识别，再复核、筛选和确认范围。见[影像识别种植](./workflows/imagery.md)。
- **大项目的识别与复核**：后台任务不因离开工作台而取消。确认细化失败或取消时，已确认的范围保持不变。
- **首次引导与资产库**：先检查环境，再通过[内置资源中心](./resources/center.md)准备推荐资源。同 ID、内容不同的 `.vfa` 可明确确认替换，已保存方案不随之改动。
- **退出提醒**：退出 Studio 时，会提醒保存实时种植中的 Explorer 工程。提醒不等于已保存场景，请在 Explorer 中确认。

完整变更见 [1.2.0 发布说明](https://github.com/Mr-Pardon/VerdFlow/releases/tag/v1.2.0)。

## 1.1.1

- Studio 内可浏览、筛选和导入资源，策略库可从新版提示跳到版本详情。
- [DTS 实时种植](./workflows/live.md)增加开放折线路径；SHP 面导入保留有效孔洞。

保存了新版路径数据的项目，不要直接交给旧版打开。详见 [1.1.1 发布说明](https://github.com/Mr-Pardon/VerdFlow/releases/tag/v1.1.1)。

## 1.0.2

推荐资源可包含种植方案；导入方案时可先检查所需策略与可选来源资产库。详见 [1.0.2 发布说明](https://github.com/Mr-Pardon/VerdFlow/releases/tag/v1.0.2)。

## 1.0.0

VerdFlow 将区域输入、种植策略、植被搭配、高程采样与场景输出连接成一条可复用的工作流。客户端使用 Windows x64 便携包，场景输出目标为 DTS。

### 当时支持的三个输入方式

| 入口 | 使用方式 |
| --- | --- |
| [DTS 实时种植](./workflows/live.md) | 在场景中绘制多个选区或导入 SHP，选择方案，采样并回写植被 |
| [FBX 模型种植](./workflows/fbx.md) | 按材质提取绿地，选择区域，分批生成与预览，输出 DTS XML |
| [SHP / GeoJSON + 高程](./workflows/geospatial.md) | 导入已对齐的面数据与 GeoTIFF，进入同一套种植、预览与输出流程 |

DTS 实时路线支持 **Explorer 7.1.0730 及之后版本**。FBX 路线使用本机 Blender 进行模型处理和采样；地理空间路线使用已经对齐的米制坐标，不执行投影转换。

### 从首次引导开始

首次使用可跟随[产品引导](./guide/first-use.md)准备资产、策略和运行环境，也可以跳过、暂停，并从设置继续。模型服务与作者工具包都是可选项。

引导提供 **导入推荐资源**，从资源中心下载、校验并导入资产库和策略，逐项展示结果并重试未完成项。导入不会自动信任策略，也不安装 DTS 模型或 PAK。

### 种植方案与跨库搭配

工作台和实时面板都支持 **预设方案 / 手动配置**。方案保存策略、植被搭配与全部公开参数，支持更新当前方案或另存为新方案。

可以勾选多个兼容资产库，按名称、ID、标签和分类统一检索，结果显示来源库。调整检索范围会保留已选项、权重、缩放与用途开关；方案按候选保存完整目标信息，缺少来源库时仍保留执行所需配置。

用途开关、权重自动配平与百分比缩放帮助控制每类植被的构成。具体角色与参数由策略包定义，详见[种植方案与植被搭配](./resources/mixes.md)。

### 方案复用与版本兼容

方案保留保存基线，加载时优先选用已安装、已信任且通过校验的同主版本新版策略。不自动下载、降级、跨主版本或继承信任；`0.x` 和预发布版仍精确匹配。

兼容复用不保证逐点相同。任务提交时固定实际精确包、方案快照、参数和种子，历史批次不会随资源更新而变化。详见[策略版本兼容](./resources/strategies.md#方案与策略版本兼容)。

### 调参与效果示意

Studio 的“效果与预览”和实时面板的“效果示意”使用策略自带的固定样本，展示参数、用途开关与植被参考尺度的影响。

有参考半径的候选可按实例缩放显示范围圆。图例和实心点位开关只影响示例显示；正式点位预览使用项目实际选区。见[调参时查看效果示意](./manual/effect-preview.md)。

### 多批次预览与输出

项目工作台支持继续种植、重新种植某一批，以及按批次和植被图例筛选保留点位。大视角显示区域关系，拉近后按视口加载具体点位。

输出时按所选批次补齐高程，合并保留点位生成 XML。坐标偏移只应用于本次 XML，项目中的输出文件会持续保留，直到手动删除。见[多批次与点位预览](./manual/batches.md)和[输出 XML](./manual/output.md)。

### 资源管理与任务执行

- 策略、资产库和种植方案支持批量导入与拖入导入。
- 资产库管理分类、缩略图、参考半径和参考高度，实际模型由目标场景提供。
- 策略包携带用途说明、推荐素材、构图示意与参数样本，界面按包内容展示。
- 长任务显示耗时与进展，支持取消和执行中重新进入工作台。
- 实时种植按空间窗口组织高程采样，单个选面采样失败时保留其他可完成选面的结果。
- 选区支持统一显隐；成功完成的选面取消勾选并隐藏边界，仍保留在列表中供复用。
- 实时 XML 导入等待真实回执；DTS 正在执行原生导入时，取消等待不保证撤销导入。

## 获取与升级

从 [GitHub Releases](https://github.com/Mr-Pardon/VerdFlow/releases)获取 Windows x64 便携包与对应发布说明。升级前备份用户数据和项目目录，再按[安装与准备](./guide/install.md)及[数据备份与更新](./reference/backup.md)操作。

在 **设置 → 应用更新**检查新的正式版。准备就绪后，结束任务、保存 Explorer 工程、停止 DTS 实时服务，再点击 **重启并更新**。没有可用更新入口时，请从 [GitHub Releases](https://github.com/Mr-Pardon/VerdFlow/releases)下载完整便携包，解压到新目录，不要混合覆盖旧文件。
