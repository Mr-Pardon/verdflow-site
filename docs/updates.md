# 更新说明

<p class="lead">核对软件版本，也核对策略包版本。客户端更新不会改写已经保存的种植结果。</p>

## 0.3.1 · 当前手册基线

本次于 **2026-10-20** 对照产品主分支提交 `f454493` 与版本声明 `0.3.1` 更新。已核验的本地便携包与最近 Git 标签仍为 `v0.3.0`；当前仓库尚未见 `v0.3.1` 标签或便携包。手册同步不表示已经公开发布，获取入口仍以实际交付为准。

### 跨资产库搭配

工作台、方案编辑器与实时面板可以从多个兼容资产库选择植被。切库保留已选项、权重、缩放与用途开关，不需要先合并资产库。方案按候选分别记录来源，缺少来源库时仍保留完整执行信息；缩略图可退为占位图。

### 实时执行与输出

XML 整理减少重复处理；实时导入等待较久时提示耗时并继续等待真实回执。取消等待不保证撤销 DTS 已经开始的导入，应检查场景后再重试。采样收尾会尝试恢复操作前视角。

## 0.3.0 · 参数效果示意

已核对 `v0.3.0` 标签和本地便携包。Studio 的“效果与预览”和实时面板的“效果示意”可以运行策略自带的小样本，展示参数与用途开关的影响。

有参考半径的候选可按实例缩放显示范围圆；图例和实心点位开关只影响示例显示。示例不读取当前项目地形，也不替代正式点位预览。详见[调参时查看效果示意](./manual/effect-preview.md)。

## 0.2.1 · 统一种植方案

用户侧统一管理 **种植方案**，植被搭配成为其中一个步骤。工作台和实时面板提供“预设方案 / 手动配置”入口。

保存方案始终包含当前全部公开参数，取消旧版“同时保存参数”勾选项。加载历史无参数方案使用默认效果，加载带参数方案使用默认值加保存值；都不继承上一次草稿。用途分类可成组开关，参数与候选保留。见[种植方案](./resources/mixes.md)。

## 0.2.0 · 历史内测基线

以下记录 **2026-10-14 的 `v0.2.0` Git 标签与本地便携包**对应的变化；其中可选参数预设与保存界面已被 0.2.1 的统一方案流程取代。

### 与使用相关的变化

- 策略包可携带植被用途分组、推荐素材和静态构图示意，Studio 与实时面板使用同一份资料。
- 植被搭配可选择保存公开种植参数；加载预设会初始化当前参数，随机种子仍独立设置。
- 用途关闭后，关联参数按策略声明隐藏但保留原值；剩余构图由策略版本决定。
- 资产增加可选参考高度，沿用参考半径的显式同步与运行快照边界，不自动改变生成或 XML。
- 实时搭配工作区分开浏览与已选配置，支持分类、搜索和分页；窄窗口通过页签切换。
- 实时保存操作区分“仅本次应用”与“保存植被搭配并应用”，在独立窗口确认更新或另存。
- 长任务允许持续执行并显示耗时、提示与取消；项目重入、取消状态及大点位预览读取有稳定性修复。

### 配图与适用范围

手册中的用途示意和新版工作区配图使用真实组件与隔离配置。用户提供的部分流程截图来自旧版，仍用于说明区域、批次与输出操作；现行名称和保存方式以正文及标注的新版图为准。

## 0.1.4 · 历史内测基线

0.1.4 采用卡片式种植引导，将种植方式、植被搭配与效果调整分开呈现。旧包不包含上面全部 `0.2.0` 改进。

0.1.x 内测阶段已建立 DTS 实时种植、FBX 项目、SHP / GeoJSON + GeoTIFF 路线，以及资产分类、参考半径、多批次预览与 XML 留档等能力。

这些能力属于持续演进中的产品，不应理解为所有复杂数据均已验证，或已经具备正式发布后的长期兼容承诺。

## 正式发布前

本站下载入口会在 VerdFlow 正式开源后链接真实的 GitHub Releases。站点和产品独立维护；更新手册不意味着产品版本也已发布。

发布前将再次核对：页面中的版本与界面、输入格式与限制、包模板、素材授权及实际下载链接。
