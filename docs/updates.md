# 更新说明

<p class="lead">了解 VerdFlow 1.0.0 的工作流、资源版本与升级方式。</p>

## 1.0.0

VerdFlow 将区域输入、种植策略、植被搭配、高程采样与场景输出连接成一条可复用的工作流。客户端使用 Windows x64 便携包，场景输出目标为 DTS。

### 三个开始入口

| 入口 | 使用方式 |
| --- | --- |
| [DTS 实时种植](./workflows/live.md) | 在场景中绘制多个选区或导入 SHP，选择方案，采样并回写植被 |
| [FBX 模型种植](./workflows/fbx.md) | 按材质提取绿地，选择区域，分批生成与预览，输出 DTS XML |
| [SHP / GeoJSON + 高程](./workflows/geospatial.md) | 导入已对齐的面数据与 GeoTIFF，进入同一套种植、预览与输出流程 |

DTS 实时路线支持 **Explorer 7.1.0730 及之后版本**。FBX 路线使用本机 Blender 进行模型处理和采样；地理空间路线使用已经对齐的米制坐标，不执行投影转换。

### 种植方案与跨库搭配

工作台和实时面板都支持 **预设方案 / 手动配置**。方案保存策略、植被搭配与全部公开参数，支持更新当前方案或另存为新方案。

可以从多个兼容资产库选择植被。切换浏览库会保留已选项、权重、缩放与用途开关；方案按候选保存完整目标信息，缺少来源库时仍保留执行所需配置。

用途开关、权重自动配平与百分比缩放帮助控制每类植被的构成。具体角色与参数由策略包定义，详见[种植方案与植被搭配](./resources/mixes.md)。

### 调参与效果示意

Studio 的“效果与预览”和实时面板的“效果示意”使用策略自带的固定样本，展示参数、用途开关与植被参考尺度的影响。

有参考半径的候选可按实例缩放显示范围圆。图例和实心点位开关只影响示例显示；正式点位预览使用项目实际选区。见[调参时查看效果示意](./manual/effect-preview.md)。

### 多批次预览与输出

项目工作台支持继续种植、重新种植某一批，以及按批次和植被图例筛选保留点位。大视角显示区域关系，拉近后按视口加载具体点位。

输出时按所选批次补齐高程，合并保留点位生成 XML。坐标偏移只应用于本次 XML，项目中的输出文件会持续保留，直到手动删除。见[多批次与点位预览](./manual/batches.md)和[输出 XML](./manual/output.md)。

### 资源管理与任务执行

- 策略、资产库和种植方案支持批量导入与拖入导入。
- 资产库管理分类、缩略图、参考半径和参考高度，实际模型由目标场景提供。
- 策略包携带用途说明、推荐素材、构图示意与参数样本，界面按包内容展示。
- 长任务显示耗时与进展，支持取消和执行中重新进入工作台。
- 实时种植按空间窗口组织高程采样，单个选面采样失败时保留其他可完成选面的结果。
- 实时 XML 导入等待真实回执；DTS 正在执行原生导入时，取消等待不保证撤销导入。

## 策略包版本

策略包独立于客户端管理版本。本手册介绍以下三个版本，资源与更新内容可在 [VerdFlow 资源中心](https://mr-pardon.github.io/verdflow-resources/)查看。

| 策略 | 版本 | 组织方式 |
| --- | --- | --- |
| [层次生态群落](./strategies/community.md) | 2.2.2 | 连续地表基质与较高主景组合，形成自然的层次与疏密变化 |
| [草坪点景组团](./strategies/lawn.md) | 1.0.2 | 连续草坪中布置完整的点景组团 |
| [通用行道树](./strategies/street-trees.md) | 2.0.2 | 按绿带宽度组织灌木排与沿线乔木 |

导入新包后审阅其来源与内容，再确认信任。种植方案绑定策略版本，客户端升级不会自动迁移全部方案，也不会重新计算已经保存的批次或 XML。

## 获取与升级

从 [GitHub Releases](https://github.com/Mr-Pardon/VerdFlow/releases)获取 Windows x64 便携包与对应发布说明。升级前备份用户数据和项目目录，再按[安装与准备](./guide/install.md)及[数据备份与更新](./reference/backup.md)操作。

## 提交反馈

在 [VerdFlow GitHub 仓库](https://github.com/Mr-Pardon/VerdFlow/issues)反馈问题时，提供客户端版本、策略包版本、输入路线、失败步骤与脱敏错误信息。可复现的小范围样例有助于判断问题，详见[常见问题](./reference/troubleshooting.md)。
