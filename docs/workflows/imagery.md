# 从影像识别绿地

<p class="lead">手里有影像、还没有绿地面时，先在本机识别候选区域，复核后再种植。</p>

**本页流程：准备两份 TIF → 创建项目 → 复核识别范围 → 确认提取区域。** 软件先找出“可能适合种植的地方”，不是看到绿色就直接种树。

## 1. 准备影像与高程

### 为什么需要两份文件？

| 文件 | 内容与用途 |
| --- | --- |
| **RGB 影像** | **从上方看到的卫星地形影像**，用来识别可能是植被的地方，提供范围依据 |
| **地形高程** | **各位置的地面高度数据**，输出时让植被落在对应高度 |

两份文件都以 `.tif` 或 `.tiff` 结尾，**扩展名相同不代表内容相同**。选取前需确认哪一份是地形影像、哪一份是高程，不要把同一份 TIF 填进两个位置。

::: tip 遇到问题可以确认一下这三项
地形影像应是 **RGB 整数波段，数值 0–255**；地形高程应是**单波段**；两者使用**同一米制投影、位置对齐，且有效高程覆盖要种植的范围**。NoData 是“这里没有高度值”，不是高度为零；缺口可能在最后输出时才导致采样失败。
:::

Windows x64 便携包内置本地 CPU 识别环境，**不需要 Blender、在线模型服务或 API Key**。需要转换投影或单位时，先在 GIS 工具完成，VerdFlow 不会自动转换。若已经有画好的区域面，直接走 [SHP / GeoJSON 路线](./geospatial.md)，无需再从影像识别一遍。

## 2. 创建项目并开始识别

1. 从 **多源工作台 → DTS → DTS 项目工作台**进入，选择 **影像 GeoTIFF**。
2. 在 **RGB 影像**中选彩色地形 TIF，在 **地形高程**中选配套的高度 TIF。
3. 填写**项目名称**，为**保存位置**选择父目录。软件会新建项目目录保存本次识别与种植状态，不是把结果覆盖回原始影像。
4. 点击 **开始识别**，等待本地后台任务完成。

<Shot src="/media/studio-create-imagery.webp" alt="影像项目创建面板，分别填写 RGB 影像、地形高程、项目名称和保存位置" caption="真实创建组件与隔离演示值；彩色影像和地形高程应分别选择。" />

**完成标志：进入“影像提取”，能看到原图、识别范围和右侧“确认种植范围”面板。** 识别期间离开工作台不会取消任务，可从项目管理器重新进入；不再需要时使用任务取消操作。

## 3. 看懂识别结果，决定保留哪些区域

**候选区域**是提取结果中被认为可能是植被的一块范围，仍需经过人工判断。**保留**表示准备纳入种植区域；**未纳入 / 手动排除**表示不采用；打开细化后出现的**拟留白**是建议挖空、不种植的位置。以当前面板底部图例为准，不要只凭颜色猜。

<Shot src="/media/studio-imagery-extraction-review.webp" :width="1658" :height="930" alt="影像提取复核界面，显示原始影像、候选覆盖、最小区域过滤、细化种植范围和确认提取区域按钮" caption="用户提供的影像操作截图；示例已启用细化，图中的数值不是推荐给所有数据的通用参数。" />

### 先核对大片，再排除误识别

1. 先看整体位置，再放大到道路、建筑边缘、裸地等容易误认的地方。用画布右上角的 **原图 / 显示区域**按钮切换，对照影像与覆盖范围。
2. 若某块不该种植，打开 **查找区域**，点击对应条目定位，**取消它的保留勾选**。拿不准时先排除，不必为了保留数量而接受可疑区域。
3. 调整错了，可使用 **撤销上次调整**。排除整块候选和在候选内部留空不同，后者见下一步。

### 零碎小块太多时，再用“最小区域”

**最小区域按像素数过滤，不是平方米。** 小于阈值的候选会被隐藏，并且不纳入本次确认；它不是只让画布少显示一些颜色。

从较小值逐步提高，同时观察“将保留”的数量和实际范围；误过滤了有用的小绿地，可降低阈值或点击 **重置**。不同影像的像素代表不同大小的地面，不要直接照抄截图数值。

## 4. 需要避开内部裸地时，细化范围

**留白是在一块已保留的绿地内部，挖出不种植的部分**，例如裸岩、裸土；它不是把整块区域取消。第一轮不需要细化时，可以保持关闭，直接到下一步确认。

| 控件 | 作用与检查方法 |
| --- | --- |
| **自动留白** | 先让软件建议内部裸露斑块。**放大对照原图**，检查“拟留白”是否真该空出来 |
| **手动调节 → 留白强度** | 自动结果不合适时调整留空程度。向“多留白”调整后，**不要把需要种植的地方也大量挖空** |
| **最小留白斑块** | 过滤太零碎的小洞，单位仍是**像素**。0 表示不限，不是关闭留白 |

**细化预览还没有保存。** 应放大观察关键位置，不能只在全图视角下判断；识别和留白都不能保证自动分清每条道路或每处岩石。

## 5. 确认提取，进入区域选择

1. 核对右侧保留数量不为零，放大检查边界、误识别区域与拟留白。
2. 点击 **确认提取区域**，等待确认任务完成。若启用了细化，这一步才会把确认的留白落实到区域中。
3. 进入 **区域选择**后，再检查最终范围。区域内部留空的地方会作为不种植的孔洞；这时还没有植被点位。

**完成标志：能在“区域选择”中选择本批要种的面。** 影像提取阶段决定“哪些地方可用”，区域选择阶段决定“这一批先种哪些”，不必一次种完所有识别出的区域。

<Shot src="/media/studio-imagery-region-selection.webp" :width="1651" :height="939" alt="影像提取确认后的工作台区域选择界面，显示待种植区域和本次已选区域" caption="用户提供的影像项目截图：确认提取后，在工作台选择本批种植范围。" />

后续使用创建项目时提供的高程 TIF，不从 RGB 影像推断高度。先完成小范围种植、预览和场景验收，再扩大处理范围。

## 区域就绪，继续种植

**[进入工作台种植流程](./workbench.md#regions)**：选择本批区域 → 选用种植方案 → 预览点位 → 用高程 TIF 采样并输出 XML。

## 在这里卡住了？

| 看到的情况 | 可以怎么处理 |
| --- | --- |
| 不接受影像文件 | 确认是带空间定位的 RGB GeoTIFF，而不是普通 JPG、截图或把图片改成 `.tif` 后缀 |
| 没有可确认的区域 | 降低或重置“最小区域”，检查是否把候选都排除了；仍没有时检查原始影像是否合适 |
| 细化预览不对 | 先关闭细化核对原始候选，再调整留白；预览不能代替对原图的人工判断 |
| 确认失败或取消 | 原有已确认范围不会因此被覆盖；重新进入先核对当前范围，再决定是否重试 |
| 点位生成成功，最后高程采样失败 | 检查高程 TIF 的覆盖、坐标和无数据缺口；识别成功不等于每个位置都有有效高度 |
