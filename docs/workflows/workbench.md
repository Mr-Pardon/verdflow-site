# 工作台种植流程

<p class="lead">区域准备好了，接下来选一套方案、生成点位，再决定输出哪些结果。</p>

本页接续 [FBX 提取](./fbx.md)、[影像识别](./imagery.md)和 [SHP / GeoJSON 导入](./geospatial.md)。三种输入都在 **DTS 项目工作台**完成后续操作，**不会像实时种植一样直接写入当前 DTS 场景**。

**第一次的目标：选一小块 → 用现成方案生成 → 检查分布 → 输出 XML → 导入 DTS 核对。** XML 是 DTS 能读取的植被位置与模型引用文件，不包含植被三维模型本身。

## 1. 选择本批区域 {#regions}

进入项目的 **区域选择**，先检查面的位置、轮廓和内部留空，再选择这一轮要种的区域。**一批**就是使用同一套配置完成的一轮种植，不要求一次选完整片地形。

密集区域在远景优先显示概览，放大后再显示更多边界细节。预览显示的精简不会改变种植实际使用的边界。

| 想做什么 | 操作 |
| --- | --- |
| 选择一个面或一片区域 | 左键点击或拖动框选；普通选择会替换当前选择 |
| 在现有选择上追加 / 切换 | 按住 **Shift** 追加；按住 **Ctrl** 切换命中区域的选中状态 |
| 移动画布、查看细节 | 中键拖动平移，滚轮缩放；画面找不到时用右上角 **适配视图** |

查看右侧 **已选**数量，确认大于零后点击 **进入种植**。**清空选择**只清除本次选中，不会删除原始区域。

<Shot src="/media/studio-imagery-region-selection.webp" :width="1651" :height="939" alt="工作台区域选择画布中的待种植面、已选区域和周边参照区域" caption="用户提供的工作台操作截图：高亮本次已选区域，周边区域保留为空间参照。" />

已有批次占用的面不能重复选来叠加种植。想改某一批，回到预览使用[重新种植这一批](../manual/batches.md#重新种植某一批)，不必先删除旧结果。

**完成标志：进入植被种植面板，显示本次已选区域数量。**

## 2. 选择方案并开始种植 {#plant}

**种植方案**是一套已经配好的种植方式、具体植被和构图参数。第一次不必逐个配置，优先使用 **预设方案**：

1. 在方案列表中选择适合用途的一套，例如连续草坪或成片林地，查看其说明和摘要。
2. 确认最终导入的 DTS 场景中已有方案引用的植被模型。**导入方案或资产库不会同时安装模型文件。**
3. 无需调整时点击 **开始种植**，等待生成本批点位。

::: tip 列表里没有可用方案？
先按[获取第一套资源](../guide/first-use.md)导入推荐资源，或到 Studio 侧栏左下角的 **资源中心**获取方案及依赖。策略提示未信任时，先审阅来源再确认信任；不要为了继续操作信任来源不明的代码。
:::

需要微调时再进入 **调整方案**。这里的修改只影响本次配置，不会自动覆盖已保存的方案；需要复用新设置时，主动更新或另存[种植方案](../resources/mixes.md#保存方案与参数)。

### 没有合适的方案时

选择 **手动配置**，按顺序完成：

1. **种植方式**：选择策略和版本，审阅来源后确认信任。区域面需要面策略，不使用开放折线的沿线树池策略。
2. **植被搭配**：按植被用途添加候选，设置权重、缩放和用途开关。可以跨多个资产库选材，见[植被搭配](../resources/mixes.md#给每个用途配置植被)。
3. **效果与预览**：调整策略公开参数。固定样本帮助比较效果，但不是本批选区的真实点位；最后仍需点击 **开始种植**。

<Shot src="/media/studio-parameter-effect-preview.webp" :width="1186" :height="649" alt="工作台构图参数与右侧策略固定样本的效果示意" caption="用户提供的参数与效果示意截图；右侧为策略固定样本，不是当前选区点位。" />

正式随机种子单独设置，不随种植方案保存。任务执行时查看项目状态；离开工作台不会取消任务，需要中止时使用取消操作，等任务结束后再重新生成。

**完成标志：进入“点位预览”，看到本批点位和对应植被图例。** “效果示意”侧板不算这一步完成，它只是在固定小样本上预览参数。

## 3. 检查点位与继续种植 {#review}

点位代表每株植被的位置，**不是已经渲染出来的三维植被**。先看疏密、边界和组合是否合适，再按批次展开图例；图例显示实际分配的植被名称，不再按策略角色区分。

勾选图例表示保留在当前预览和后续输出中，取消勾选用来筛掉不需要的植被。大视角主要看区域关系；**要看具体点位，请放大**，不要把远景没有画满点误认为生成失败。

<Shot src="/media/studio-point-preview-detail.webp" :width="1657" :height="930" alt="点位预览中的植被参考范围、当前批次和按植被分类的图例" caption="用户提供的点位预览截图：放大检查植被分布，按批次和图例保留输出内容。" />

- **分布合适，还要种其他区域**：点击 **继续种植**，保存这批结果并回到区域选择。下一批可以使用其他方案。
- **想换一批的效果**：使用该批的重新种植操作，核对新结果后再提交替换。
- **准备交付**：保留需要的点位，点击 **输出预览点位**。这时只是准备输出，尚未开始高程采样。

批次筛选、删除和重新种植的区别，见[多批次与点位预览](../manual/batches.md)。

**完成标志：点击“输出预览点位”后进入输出页，批次和点位计数与保留选择一致。**

## 4. 生成 XML {#export}

**高程采样**是根据每个点的位置，查询对应的地面高度，让植被不再只有平面位置。它在这一阶段进行，不是在点位刚生成时进行。

1. 核对保留的批次、区域和点位计数，不应为零。
2. 第一次没有明确的坐标调整要求时，将 **XML 坐标偏移**的 X、Y、Z 保持为 **0**，不要用试填偏移弥补数据不对齐。
3. 点击 **生成 XML**，等待采样与文件生成。系统为所选批次补齐或复用高程，按保留的资产合并输出，不是拼接历史 XML。

| 项目从哪里开始 | 输出使用什么高程 |
| --- | --- |
| FBX 模型 | 由 Blender 从项目模型采样 |
| 影像 GeoTIFF | 创建项目时提供的高程 TIF，不从 RGB 影像推断 |
| SHP / GeoJSON | 创建项目时提供的高程 TIF |

<Shot src="/media/studio-output.webp" alt="项目 XML 输出面板，包含坐标偏移、历史文件和另存为入口" caption="真实输出组件与隔离演示数据；展示结果留档，不代表当前项目已输出。" />

**完成标志：“项目 XML”列表新增一条文件记录。** 点击该条目的 **另存为**，把 XML 放到方便导入 DTS 的位置。历史 XML 不会因为继续种植或重新进入输出而消失，除非手动删除。

**点位可见不等于高程已就绪。** 项目输出不会像实时路线那样跳过失败面继续导入；采样失败时检查高程来源，修复后重试，或排除相关批次。偏移只影响本次 XML，不改变原始点位，也不能代替坐标转换。详见[输出 XML 与坐标偏移](../manual/output.md)。

## 5. 在 DTS 检查实际结果

把另存的 XML 导入 DTS 测试工程，核对**位置、高程、模型和大小**。拿到 XML 表示工作台完成了输出，并不代表 DTS 场景已经更新。确认小范围结果无误后，再扩大种植范围。

具体核对方式见[在 DTS 验收](../manual/output.md#在-dts-验收)。想重新检查输入，可以回到 [FBX](./fbx.md)、[影像](./imagery.md)或 [SHP / GeoJSON](./geospatial.md)指南。
