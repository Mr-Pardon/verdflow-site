# DTS 实时种植

<p class="lead">直接在已有 DTS 场景里选区，生成植被并写入场景。</p>

## 1. 连接目标场景

先在设置中配置 Explorer 根目录，详见[安装与准备](../guide/install.md)。从 Studio 的 **多源工作台 → DTS → 实时选区种植**进入，点击 **启动实时种植**。

<Shot src="/media/live-workbench-session.png" alt="Studio 实时种植工作台中的服务控制、Explorer 连接状态和实时事件" caption="历史操作截图：服务已就绪、Explorer 尚未连接；继续打开 Explorer 与 WebUI 后再确认连接成功" />

等待 Explorer 打开后进入项目，打开右侧菜单栏最下面的 **WebUI**，确认面板显示“DTS Explorer 已连接”，并且目标地形已经加载。

<Shot src="/media/live-explorer-panel.png" alt="DTS Explorer 场景右侧打开的 VerdFlow 快速种植面板，显示已连接状态" caption="历史场景截图：用于定位 WebUI 与连接状态；当前版本另有预设方案入口，以正文为准" />

第一次使用先做一个小选区，验证植被模型名称和高程。实时写入会改变 DTS 场景；不要把大范围测试当作只读预览。

## 2. 选预设方案，或手动配置

主面板提供 **预设方案 / 手动配置**两个入口，选择后才会展开选区控件。已有合适方案时，打开方案选择面板，选中后会带回策略、植被和公开参数；需要改变时点击 **调整方案**。

手动配置时先选择策略卡片，同一策略通过版本选择切换。新包需要先确认信任；切换版本后重新检查搭配，方案绑定精确版本，不是任意同名策略。

<Shot src="/media/live-configuration-entry.png" alt="DTS 实时种植面板的预设方案与手动配置两个入口，上方显示 Explorer 已连接" caption="用户提供的实时面板截图：使用已保存的方案，或从策略与植被搭配开始配置" compact />

使用预设且无需调整时，完成选区后即可开始种植，不必逐项重做第 4、5 步。

## 3. 准备种植选区

使用选区工具栏的三个入口：**绘制选区、导入 SHP、导出 SHP**。

- 绘制：依照 DTS 当前绘制交互完成一个闭合面，可以连续添加多个面。
- 导入：使用 SHP 数据或包含必要伴随文件的 ZIP，将 Polygon 选区加载到场景与列表。
- 导出：将已勾选的选区统一导出为 SHP ZIP，以便以后复用。导出选面不需要先做高程采样。

实时导入只接收 SHP 或包含单套 SHP 数据的 ZIP，不直接接收 GeoJSON。多部件面会拆为独立选区；**含孔洞的面当前会拒绝导入**，不会悄悄把孔洞填满。格式、体量限制及替代路线见[实时 SHP 限制](../reference/data.md#实时-shp-导入限制)。

场景中的贴地 Polygon 用于显示边界。它可能不能被 DTS 直接作为 Polygon 拾取；面板会根据点击坐标判断命中的选区并定位列表。

### 管理较多选区

可搜索名称或编号、分页浏览、全选或反选。勾选决定本次执行的范围。清空选面需要二次确认；不要把“取消勾选”和“删除选区”混淆。

## 4. 加载或手动配置植被搭配

调整已有方案时，现有搭配会回填。工作区按 **植被用途、选择植被、已选植被**分区；先看用途示意与推荐，再通过分类和搜索寻找候选。可以切换兼容资产库继续选植被，已选候选、权重、缩放和开关都会保留。

浏览列表与已选配置独立滚动，大资产库按页查看；窄窗口使用“选择植被 / 已选植被”切换，不必把配置挤在长列表底部。

权重显示为百分比并自动配平到 100%。缩放可选择资产默认、固定值或随机范围；例如 **80–120%** 表示模型原始尺寸的 0.8–1.2 倍。

可以关闭不需要的用途，但至少保留一个启用用途。关闭后是否重排其他用途由当前策略版本决定，参见[内置策略](../strategies/overview.md)。

<Shot src="/media/live-mapping-v031.webp" alt="0.3.1 实时植被搭配工作区，包含资产库选择、用途示意、分类搜索和已选候选" caption="0.3.1 真实实时组件与隔离演示植被，不连接或修改真实场景" />

点击 **仅本次应用**回到主面板，只更新本次配置。调整好构图参数后，点击主面板底部的 **保存种植方案**，在确认窗口选择更新当前方案或另存为新方案。保存包含当前全部公开参数，不再单独勾选；点击返回调整会保留草稿。

方案不包含随机种子，细节见[保存方案与参数](../resources/mixes.md#保存方案与参数)。

## 5. 调整效果并开始种植

展开构图参数，调整当前策略公开的间距、覆盖率等参数。更换随机种子可以在同一规则下探索新的分布。

仅与关闭用途关联的参数会隐藏，但值仍保留。加载方案时使用策略默认值加保存参数重新初始化；历史无参数方案使用默认效果。

点击 **效果示意**可打开侧板，在策略自带的小样本上查看调参结果。它不是当前选面的生成结果，也不采样高程。示例中的图例和实心点位开关只影响显示，详见[效果示意](../manual/effect-preview.md)。

确认选面、策略和搭配都就绪后，点击开始种植。面板会显示生成点位、高程采样与 XML 导入等过程阶段。

## 6. 采样与导入

多面执行会按空间窗口组织采样，并调整视角帮助 DTS 加载采样范围。收尾时尝试恢复采样前的视角，再统一导入 XML。大范围任务需要更多时间，XML 导入期间 DTS 可能暂时不响应。

采样完成后仍会经历“整理高程结果并生成 XML”和导入等待。导入等待较久时只提示耗时，继续等真实回执，不会因为达到内置超时就自动判定失败。

取消或关闭面板只能停止本页等待，不能保证撤销 DTS 已经开始的原生 XML 导入。再次种植前先检查场景，避免重复导入。

单个选面采样失败不会拖垮其他可完成的选面。执行结束后检查失败列表，再针对失败面重试。**全部选面失败时，不会生成 XML。**

::: warning 再次点击种植前
确认前一次导入是否完成，以及场景是否已存在对应植被。实时路线不是项目批次的持久化管理器，不能假设重新打开面板后自动恢复全部历史选面和执行状态。
:::

## 复用选区

导出 SHP 保存的是面几何，不包含已种植点位、策略参数、植被搭配或高程结果。下次导入后仍需选择搭配并重新采样。

数据要求见[输入数据检查](../reference/data.md)，搭配设置见[植被搭配](../resources/mixes.md)。
