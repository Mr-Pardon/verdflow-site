# DTS 实时种植

<p class="lead">直接在已有 DTS 场景里用面选区或绘制路径，生成植被并写入场景。</p>

**本页流程：连接场景 → 选择种植方案 → 准备选区 → 开始种植 → 检查并保存工程。** 实时路线使用 DTS 场景中的地形采样高度，无需另选高程 TIF。

## 1. 连接目标场景

::: info Explorer 版本要求
实时种植当前支持 **DTS Explorer 7.1.0730 及之后版本**。更早版本不承诺兼容。
:::

1. 按[安装与准备](../guide/install.md#dts-连接)配置 Explorer 根目录，并检查可用状态。
2. 从 Studio 的 **多源工作台 → DTS → 实时选区种植**进入，点击 **启动实时种植**。

<Shot src="/media/live-workbench-session.png" alt="Studio 实时种植工作台中的服务控制、Explorer 连接状态和实时事件" caption="服务已就绪、Explorer 尚未连接；继续打开 Explorer 与 WebUI 后再确认连接成功" />

3. 等待 Explorer 打开，进入目标工程，确认地形已加载。
4. 打开右侧菜单栏最下面的 **WebUI**，显示 VerdFlow 快速种植面板。如果菜单中没有 WebUI，先在[偏好设置中启用 WebUI 控制](../guide/install.md#dts-连接)。

<Shot src="/media/live-explorer-panel.png" alt="DTS Explorer 场景右侧打开的 VerdFlow 快速种植面板，显示已连接状态" caption="在 Explorer 场景中打开 WebUI 并确认连接状态；方案配置入口见下文" />

**完成标志：面板显示“DTS Explorer 已连接”，目标地形可以正常浏览。** Studio 中的服务已启动，不等于 Explorer 中的面板已连接。

第一次使用先做一个小选区，验证位置、高程和植被模型。实时种植会直接改变当前 DTS 场景。

## 2. 选预设方案，或手动配置

### 优先使用预设方案

**种植方案**保存了种植方式、植被搭配和参数，可以直接载入使用。

1. 在快速种植面板选择 **预设方案**，点击 **选择种植方案**打开方案列表。
2. 确认目标 DTS 工程中已准备方案引用的植被模型。导入方案或资产库只导入配置信息，不会同时安装模型或 PAK。

随后进入选区操作；无需调整方案时，可跳过第 4 步，在选区完成后直接[开始种植](#_5-调整效果并开始种植)。

::: tip 暂无可用方案
先按[获取第一套资源](../guide/first-use.md)准备推荐资源，或从 Studio 侧栏左下角的[资源中心](../resources/center.md)导入方案及依赖。策略执行前需审阅来源并确认信任。导入后若实时面板未更新，点击顶部圆形箭头 **同步 Studio 中的策略与种植方案**。
:::

### 调整方案或手动配置

已有方案需要修改时，点击 **调整方案**，现有配置会回填。没有合适方案时，返回配置入口选择 **手动配置**，先选择策略卡片，再按第 4、5 步配置植被和参数。同一策略通过版本选择切换。

已有方案可使用通过校验的同主版本新版，实际版本以面板显示为准，详见[兼容规则](../resources/strategies.md#方案与策略版本兼容)。

## 3. 准备种植选区

选择配置入口后，主面板会展开 **种植选区**。面选区是需要种植的一块闭合范围，可以连续添加多个面。

| 入口 | 操作与结果 |
| --- | --- |
| **绘制选区** | 在场景中依照 DTS 绘制交互完成闭合面；完成后加入选区列表，并显示贴地边界 |
| **[拾取绿地](#pick-green-space)** | 从场景中独立建模的绿地构件提取面，追加到选区列表（VerdFlow 1.3.0 新增） |
| **导入 SHP** | 选择已有 SHP 或包含单套 SHP 数据的 ZIP，将面加载到场景和列表 |
| **导出 SHP** | 将列表中已勾选的面统一保存为 SHP ZIP，供后续复用；不需要先种植或采样 |

使用 **沿线树池种植**时，选区控件会改为 **[绘制路径](#沿线种植-绘制开放折线)**。**通用行道树仍使用绿带面**，不使用开放折线。

### 拾取绿地：从场景构件提取选区 {#pick-green-space}

::: warning 建模前提：绿地应是独立构件
建模时，应将待种植的绿地面**单独合并为绿地构件**，不要与道路、铺装等非种植区域合在同一构件中。工具提取的是**所选构件在俯视下可见的轮廓**，不会按材质或颜色自动区分草地和道路。若两者合在一起，提取结果也可能包含道路等区域。
:::

1. 在 **种植选区**中点击 **拾取绿地**，再点击场景中的绿地表面。检查高亮范围，确认选中的是独立的绿地构件。
2. 点击 **确认提取**，提取整个构件的可见范围。若只需要其中一部分，先点 **限定范围**，在场景中绘制一个闭合面，再点 **提取范围内**。只保留构件与绘制范围重合的部分。
3. 提取完成后，检查追加到列表中的选区及其边界。若道路等区域与绿地已连成同一个提取面，先取消勾选该面，再用 **绘制选区**明确边界，或在模型中拆分构件后重新提取。

<Shot src="/media/home-region-live.webp" :width="1914" :height="1079" alt="DTS 场景中提取的绿地面，以及实时种植面板的拾取绿地入口和选区列表" caption="DTS 实拍：提取出的面会加入选区列表。图中的滚轮提示是 1.3.0 的操作方式，不适用于 1.3.1。" />

**提取只准备选区，不会自动种植。** 未提供 **拾取绿地** 的版本可使用 **绘制选区** 或 **导入 SHP**。

### 确认本次种植范围

1. 在场景中检查边界的位置和形状，核对是否覆盖待种植地面。
2. 在列表中**勾选本次参与种植的面**。已有多个面时，可只勾选一部分，分次执行。
3. 查看列表上方的已选数量，确认大于零。点击场景中的选区，也可定位到对应列表条目。

<Shot src="/media/live-region-selection.webp" :width="1920" :height="1080" alt="DTS 场景中的多个贴地种植选区，与实时面板内的选区勾选、搜索、定位和显隐控件对应" caption="用户提供的实时操作截图：场景边界与列表对应，勾选决定本次种植范围。" />

**完成标志：列表中至少有一个选区被勾选。** 选区边界只是范围预览，此时尚未生成植被。

::: details 导入 SHP 的数据要求
同名 `.shp`、`.shx`、`.dbf` 放在同一目录；使用 ZIP 时应包含单套完整数据。实时路线不直接接收 GeoJSON。多部件面会拆为独立选区，面内部有效孔洞作为不种植的范围保留。格式和大范围数据的使用建议见[实时 SHP 导入要求](../reference/data.md#实时-shp-导入限制)。
:::

### 管理较多选区

选区较多时，可按名称或编号搜索、分页浏览。几个控件分别作用于不同对象：

| 控件 | 作用 |
| --- | --- |
| **勾选 / 全选 / 反选** | 决定本次种植范围；全选、反选作用于全部分页，不只是当前页 |
| **定位图标** | 将场景视角移到对应选区 |
| **眼睛图标** | 控制边界显示；工具栏可统一显隐，**不改变种植勾选** |
| **移除 / 清空选面** | 移除选区及其边界预览；清空需要二次确认，**不会擦除已种植的植被** |

### 在场景中批量勾选

已有面选区时，在实时面板选择 **刷选**或**刷除**启用笔刷。在场景中按住**左键拖动**，批量勾选或取消勾选刷到的面。**刷除只取消本次种植勾选，不删除选区或已有植被。** 未勾选的面保留淡色轮廓，方便重新选回。

| 要做什么 | 鼠标操作（1.3.1） | 快捷键 |
| --- | --- | --- |
| 调整笔刷大小 | 编辑时，滚轮向上放大笔刷、向下缩小；漫游时滚轮仍用于场景缩放 | 无 |
| 切换刷选与刷除 | 编辑时按**中键**，或将鼠标移入左下热区 | 单按 **Shift** 刷选，单按 **Ctrl** 刷除 |
| 切换编辑与漫游 | 按**右键**进入漫游，或将鼠标移入左上热区切换 | 笔刷启用后，单按 **Alt** 切换 |

由 VerdFlow 启动的 Windows 版 **DTS Explorer** 中，场景获得焦点后也可以使用这些快捷键，无需先点回实时面板。若场景内快捷键不可用，可继续使用鼠标和热区。

::: tip 从 1.3.0 升级
从 1.3.1 起，**滚轮只调笔刷大小，不再切换刷选和刷除**。中键用于切换刷选与刷除，不再用于进入漫游。
:::

## 4. 加载或手动配置植被搭配

**使用预设且无需更换植被时，可直接进入第 5 步。** 手动配置或调整方案时，在 **植被搭配**中打开 **选择植被 / 调整植被搭配 / 编辑植被搭配**；按钮名称随当前配置状态变化。也可通过 **从已有方案载入**复用当前策略的搭配。

### 按植被用途选择候选

**植被用途对应策略角色，表示空间分布中的职责，不限定某一种树种。** 例如一个组团主景用途可以同时搭配橡木和榆树，由权重决定各候选被选中的概率。

1. 在 **植被用途**中选择需要配置的用途，参考用途示意和推荐。
2. 在 **检索范围**中勾选兼容资产库，再通过分类和搜索寻找植被。一个用途可以配置一种或多种候选。
3. 在 **已选植被**中核对候选，设置权重、缩放方式和用途开关；不需要的候选可移除。调整检索范围不会清空这些设置。
4. 点击 **应用**回到主面板，检查 **植被搭配**是否显示 **已就绪**。

<Shot src="/media/live-mapping-v100.webp" alt="实时植被搭配工作区，包含多库统一检索、用途示意、分类搜索和已选候选" caption="1.0.0 真实实时组件与隔离演示配置，不连接或修改真实场景" />

### 权重、缩放与用途开关

| 设置 | 作用与说明 |
| --- | --- |
| **权重** | 同一角色内各候选的**相对概率**。橡木 70%、榆树 30% 是随机分配比例，不保证每 10 株刚好 7 株与 3 株；面板自动配平到 100%。**权重不控制种植密度** |
| **缩放方式** | 控制植被相对原始模型的大小。**资产默认**沿用资产建议的规则；**固定**统一使用一个比例，如 80%；**随机范围**逐株取值，如 80–120% |
| **角色启用**（植被用途开关） | 控制本次是否输出该用途的点位。关闭后候选和设置仍保留；至少启用一个用途，并为启用用途配置有效植被 |

**100% 缩放就是模型原始大小**。较大的树冠或更高的缩放，可能让真实植被超出点位中心所在的面边界。

关闭某个用途后，其他用途是否重排由策略版本决定。具体规则见[常用策略](../strategies/overview.md)，多库检索和数值单位见[植被搭配](../resources/mixes.md#跨资产库选植被)与[参数参考](../reference/parameters.md)。

**完成标志：植被搭配显示“已就绪”。** 点击应用只更新本次配置，保存为可复用方案的方法见下一步。

## 5. 调整效果并开始种植

使用预设且无需调整时，核对已勾选选区和方案后，直接点击底部 **开始种植**。按钮会显示本次选中的面数或路径数。

### 需要调整效果时

1. 在手动配置中展开 **构图参数**，调整策略提供的间距、覆盖率等参数。更换随机种子可在同一规则下探索不同分布。
2. 点击 **效果示意**，在策略自带的小样本上比较效果。**这不是当前选区的生成结果，也不采样高程**；图例和实心点位开关只影响显示，详见[效果示意](../manual/effect-preview.md)。
3. 核对选区、植被搭配和参数后，点击 **开始种植**。

仅与关闭用途关联的参数会隐藏，原值仍保留。加载方案时，使用策略默认值加保存参数重新初始化；历史无参数方案使用默认效果。

::: details 将调整结果保存为种植方案
在主面板底部点击 **保存种植方案**，选择更新当前方案或另存为新方案。保存包含当前全部公开参数，不包含随机种子、选区或执行结果。临时调整不会自动覆盖原方案；点击返回调整会保留草稿。详见[保存方案与参数](../resources/mixes.md#保存方案与参数)。
:::

**完成标志：面板进入执行状态，显示生成点位、高程采样或 XML 导入等阶段。**

## 6. 采样与导入

执行依次完成 **生成点位 → 高程采样 → 生成 XML → 导入 DTS**，无需再手动导出、导入 XML。

**高程采样**根据点位的位置，从当前 DTS 地形查询高度。多面任务会自动调整视角、按空间范围采样，结束时尝试恢复原视角。大范围任务耗时较长，XML 导入期间 DTS 可能暂时不响应。

### 检查执行结果

| 结果 | 后续操作 |
| --- | --- |
| **全部完成** | 在场景中检查植被位置、高程、模型和大小 |
| **部分选面采样失败** | 展开失败列表查看具体原因，定位检查地形后点击 **仅选失败项**，再执行重试；其他可完成的选面不受单面失败影响 |
| **全部选面采样失败** | 不会生成 XML；先检查地形是否加载、采样范围和具体错误，再重试 |

成功完成种植的选面会取消勾选并隐藏边界，但仍保留在列表中；失败面继续保留待处理状态。若要再次种植或导出已完成选面，需要重新勾选；重新勾选不是撤销已有植被，再次执行可能产生重复结果。

::: warning 再次点击种植前
确认前一次导入是否完成，以及场景是否已存在对应植被。重新生成之前需**手动擦除区域内存在的植被**。
:::

### 确认写入并保存工程

**完成标志：面板收到导入成功结果，场景中能看到对应植被。** 面板显示成功但结果不符合预期时，先核对当前工程与目标模型，不要直接重复执行。

确认结果无误后，在 **Explorer 中保存工程**。Studio 的退出提醒不会自动保存 DTS 场景。

## 复用选区

需要跨会话复用选面时，勾选对应的面并 **导出 SHP**。SHP 保存的是面几何，不包含已种植点位、策略参数、植被搭配或高程结果。下次导入后仍需选择方案或搭配，并重新采样。

数据要求见[输入数据检查](../reference/data.md)，搭配设置见[植被搭配](../resources/mixes.md)。

## 沿线种植：绘制开放折线

1. 在 [Studio 资源中心](../resources/center.md)导入**沿线树池种植**并确认信任，再到实时面板选择该策略，或加载使用它的种植方案。
2. 点击 **绘制路径**，依照 DTS 绘制交互画一条开放折线。绘制顺序决定起点；不必闭合，也不能用 SHP 面替代这条路径。进入线型策略后，不会显示面选区的 SHP 导入、导出按钮。
3. 配置植被与可选树池，设置沿线间距、起点留距和转角圆滑半径。先用**效果示意**检查固定样本，再尝试一小段实际路径。
4. 点击 **开始种植**。等待高程采样和场景写入回执，检查植被间距及树池朝向。操作前先确认上一轮是否已写入，避免重复种植。

详见[沿线树池种植](../strategies/path-planters.md)。**通用行道树仍需要一个绿带面**，由策略计算中心路径，不使用这个绘制入口。

## 常见问题

| 看到的情况 | 检查方向 |
| --- | --- |
| Studio 中服务正常，实时面板仍未连接 | 确认 Explorer 已打开目标工程，并从工程右侧菜单打开 WebUI；无入口时检查偏好设置 |
| Studio 新导入的方案未显示 | 点击面板顶部的同步按钮，并检查策略是否可用、已信任 |
| 没有「拾取绿地」入口 | 核对 VerdFlow 版本与所选策略；拾取绿地用于面选区，不适用于开放折线策略 |
| 开始种植按钮不可用 | 检查连接状态、勾选数量、当前策略、植被搭配和参数；等待上一任务结束后再操作 |
| 导入成功但植被缺失或位置异常 | 核对当前工程、方案引用的模型名称及场景资源，再检查位置和高程；排查前不重复种植 |
