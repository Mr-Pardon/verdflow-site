# SHP / GeoJSON + 高程

<p class="lead">直接使用面数据与高程栅格，不必先把区域转换成 FBX。</p>

## 先确认数据已经对齐

VerdFlow 按输入数值直接处理。区域与 GeoTIFF 应处于**同一米制坐标空间**，位置、尺度与高程单位由上游数据准备保证。

::: warning 不做投影转换
这条路线不承担 CRS 检测、重投影、经纬度转换或单位换算。经纬度数值不能直接当作米制 XY 使用；缺少坐标系描述，也不会让软件自动猜测正确坐标。
:::

## 1. 创建项目与准备区域

在 DTS 工作台的项目入口选择地理空间路线。

<Shot src="/media/studio-workflow-source.png" alt="DTS 项目工作台的区域来源选择弹窗，包含 SHP / GeoJSON 路线" caption="在项目入口选择 SHP / GeoJSON 作为区域来源" />

先打开创建面板，再分别选择：

- 种植区域：SHP 或 GeoJSON 面数据。
- 地形高程：与区域对齐的 GeoTIFF。
- 项目名称与保存位置。

<Shot src="/media/studio-create-geospatial.webp" alt="地理空间种植项目创建面板，分别选择区域文件、高程文件和保存位置" caption="真实创建面板；文件名与项目目录为演示值，不指向私人数据" />

确认后创建并准备区域。SHP 的伴随文件应放在同一目录，不能只复制一个 `.shp` 文件，见[数据检查表](../reference/data.md)。

## 2. 选择区域

检查面的位置、尺度与孔洞是否符合预期。选择本批区域；大范围数据建议先用一小部分验证高程覆盖和植被密度。

<Shot src="/media/studio-region-selection.png" alt="Studio 区域选择画布中的面边界、已选区域与保存批次信息" caption="两条项目路线共用选区界面；本图仅演示选面操作" />

这条项目路线支持 Polygon / MultiPolygon 及有效孔洞，不等于支持任意线、点或未经整理的地图下载数据。不要与实时面板的 SHP 导入混淆：实时选区当前不支持带孔洞面。

## 3. 种植与预览

与 FBX 路线共用种植引导：可以直接选择 **预设方案**，也可以 **手动配置**策略与版本、植被搭配和效果参数，再生成点位。搭配支持从多个兼容资产库添加候选，切库不清空已选项。

<Shot src="/media/studio-effect-example-v031.webp" alt="效果与预览面板，参数与策略样本并排展示" caption="真实组件与合成样本；示例不使用导入的地理区域或高程" />

调参时的[效果示意](../manual/effect-preview.md)帮助比较参数；实际点位仍需对本批选区生成。保存种植方案会包含公开参数，随机种子单独设置。

可以分多批使用不同策略，最后在点位预览中统一筛选。区域面积很大时，先增大间距并控制角色数量，避免首次测试就生成过密结果。

<Shot src="/media/studio-point-preview.png" alt="Studio 点位预览中的批次列表、植被图例与预览保留点位" caption="两条项目路线共用点位预览；按批次和植被决定保留哪些点位" />

## 4. 高程与输出

点击 **输出预览点位**打开输出面板，确认筛选与偏移后再点击 **生成 XML**。系统按所选批次补齐或复用 GeoTIFF 高程，最后按资产筛选合并输出。首次采样使用所选批次保存的点集，不保证仅采样当前勾选的资产点。

高程读取使用栅格的第一波段；点位落在范围外、NoData 区域或非有限数值位置，会使相关采样失败。项目路线不会沿用实时路线的“跳过失败面并导入其余面”机制，本次组合输出会停止；可修复输入，或先排除失败批次后输出其他批次。

XYZ 偏移仅用于本次 XML，不是修正投影问题的工具。数值和坐标空间准备错误时，应回到数据源治理，而不是用一个大偏移掩盖问题。

<Shot src="/media/studio-xml-output.png" alt="Studio XML 输出面板中的 XYZ 偏移输入与项目 XML 文件列表" caption="两条项目路线共用输出面板；本次保留为 0 时不能生成新 XML" />

## 怎样确认数据可用

在 GIS 工具中同时打开区域与 GeoTIFF，检查重叠关系、像元尺寸、有效高程和单位。导入 VerdFlow 后，再用小范围结果确认输出位置。

遇到自交、孔洞关系异常或无效高程时，先在上游工具修复并重新核对。创建时通过了范围重叠检查，不代表每个生成点都位于有效高程内。
