# SHP / GeoJSON + 高程

<p class="lead">已有种植区域面和高程 TIF 时，直接建立项目，不必转换成 FBX。面也可以使用 GeoJSON 格式。</p>

**本页流程：整理区域文件 → 配好高程 → 创建项目 → 检查区域。** 这条路线采用已准备好的区域范围，不再识别绿地，也不需要给模型材质分类。

## 1. 准备区域面与高程

### 两份数据，各管一件事

| 数据 | 内容与文件 |
| --- | --- |
| **种植区域** | **画好的闭合边界**，决定“哪里能种”。选择 `.shp` 或 `.geojson` / `.json` 面数据 |
| **地形高程** | **各位置的地面高度**，决定“种在多高”。选择 `.tif` / `.tiff` 高程 GeoTIFF，第一波段应为有效高度 |

### SHP 要把整套文件放在一起

SHP 通常不只有一个文件。若拿到的是压缩包，先解压；创建项目时选择 `.shp`，其余配套文件保留在同一目录：

```text
planting.shp    ← 文件窗口中选择这一项
planting.shx    ← 配套索引，保留
planting.dbf    ← 配套属性，保留
planting.prj    ← 如有，保留坐标描述
planting.cpg    ← 如有，保留编码说明
```

**不要只拷贝 `.shp`，也不要只给其中一个文件改名。** GeoJSON 通常是一个文件，不需要这套 SHP 配套文件。更多说明见[输入数据检查](../reference/data.md#shp-不是一个孤立文件)。

::: warning 开始前请确认
**区域和高程处于同一米制坐标空间，位置对齐，水平与高程单位正确。** 通俗地说，两份数据叠在一起时，同一块地应在同一位置，距离单位应为米。VerdFlow 不做 CRS 检测、重投影、经纬度转换或单位换算；有 `.prj` 也不会自动转换。需要处理时先在 GIS 工具中完成。
:::

高程数据还要**实际覆盖要种的区域**。TIF 是一种文件格式，不代表其中一定有高度；普通彩色影像 TIF 不能当作高程。NoData 表示该位置没有有效高度，不是高度为零。

## 2. 创建项目并准备区域

1. 从 **多源工作台 → DTS → DTS 项目工作台**进入，选择 **SHP / GeoJSON**，打开创建面板。
2. 在 **种植区域**旁点击 **选择**，选中 `.shp` 或 GeoJSON 文件。使用 SHP 时，检查同目录配套文件齐全。
3. 在 **地形高程**旁点击 **选择**，选中已经对齐的高程 TIF。这里不是选区域截图，也不是选彩色地形影像。
4. 填写**项目名称**，为**保存位置**选择一个父目录，软件会创建项目目录保存后续文件和状态。
5. 核对两条文件路径，点击 **创建并准备区域**，等待后台导入完成。

**完成标志：进入“区域选择”，能看到导入的面。** 这一步不会生成植被，也不会读取当前 Explorer 场景来代替 TIF 高程；不需要为导入配置 Blender 或在线模型服务。

## 3. 检查区域是否就绪

不要只看“导入成功”，先检查：

- **轮廓是否与原始范围一致？** 对照原始面数据，检查有没有缺失或多出的区域。
- **内部应空出来的位置还在吗？** 建筑、水面等避让范围应为空，不应被填成可种植面。
- **尺度是否合理？** 不应把一小块绿地读成异常大的范围。拿不准时请数据提供者在 GIS 中核对，不要尝试用缩放植被来补偿。

这时只是准备好了区域；**高程要到输出阶段才用于点位采样**。范围有重叠，不等于所有区域都有有效高度。第一次先选一小块走完种植与输出，确认高度和位置后再扩大范围。

## 区域就绪，继续种植

**[进入工作台种植流程](./workbench.md#regions)**：选择本批区域 → 选用种植方案 → 预览点位 → 用高程 TIF 采样并输出 XML。

## 在这里卡住了？

| 看到的情况 | 先检查什么 |
| --- | --- |
| SHP 无法读取 | 是否已解压，且同名 `.shp`、`.shx`、`.dbf` 都在同一目录 |
| 提示不是面或几何无效 | 文件是否真是闭合面；自交、零面积和异常孔洞应先在 GIS 工具修复 |
| 区域位置或大小异常 | 区域与高程是否使用同一米制坐标；GeoJSON 也可能是经纬度，不能仅凭后缀判断 |
| 后续高程采样失败 | 同时在 GIS 中打开面与高程，检查范围外、NoData 缺口和高程波段，不要用 XML 偏移掩盖投影或尺度错误 |

这条**项目路线**与[实时面板的 SHP 导入](./live.md#_3-准备种植选区)不同，需要单独准备配套的 GeoTIFF 高程。手头只有彩色影像、没有区域面时，另走[影像识别种植](./imagery.md)。
