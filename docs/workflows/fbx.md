# FBX 模型种植

<p class="lead">从 FBX 场景模型提取种植面，再通过工作台完成植被种植与 XML 输出。</p>

**本页流程：准备模型 → 创建项目并分析材质 → 复核并提取绿地 → 检查区域。** 区域准备好后，再进入种植和 XML 输出；导入 FBX 本身不会自动种树。

## 1. 准备 FBX 与 Blender

准备一份**包含待种植地面的 FBX**，并确认[设置中的 Blender 路径](../guide/install.md#blender-路径)有效。Blender 会在后台读取模型和提取区域。

<Shot src="/media/studio-runtime-settings.png" alt="Studio 外部运行环境设置中的 Blender 可执行文件与 DTS Explorer 根目录，路径已遮挡" caption="配置 Blender 路径后检查可用状态；截图中的本机路径已遮挡" />

## 2. 创建项目并选择识别方式

1. 从 **多源工作台 → DTS → DTS 项目工作台**进入，选择 **FBX 模型**，在文件窗口中选中需要的 `.fbx`。
2. 在创建面板中填写**项目名称**，为**保存位置**选择一个父目录。软件会创建项目目录，保留后续文件与状态；这里不是选择 XML 导出位置。

### 按材质提取种植面

创建面板中的 **材质识别方式**，用于确定模型里的哪些表面需要提取。VerdFlow **先确定绿地对应的材质，再从使用这些材质的模型表面提取边界，形成种植面**。

材质名称可能没有规律，因此**推荐先使用 AI 辅助选择**。分析会结合**材质与对象名称、贴图名称及路径等多种线索**，生成分类建议，并提供**置信度和分析依据**；手动选择作为没有可用 AI 服务时的[备选方式](#manual-selection)。

### 使用 AI 辅助选择

先在 **运行 → 模型服务**中配置并测试一个可用服务，具体见[配置模型服务](#可选-配置模型服务)。

1. 将**材质识别方式**设为 **AI 辅助选择**，在 **模型 Provider**下拉框中选择已配置的模型服务。
2. 第一次建议关闭 **自动确认高置信材质**，先由 AI 分析、再人工复核；这仍是 AI 辅助路径，不是手动识别。开启后可自动继续提取，完成后仍应检查区域。
3. 点击 **创建并开始分析**，等待模型读取与 AI 分析。可在项目管理器重新打开项目查看状态。

<Shot src="/media/studio-create-fbx.webp" alt="FBX 项目创建面板，已选中 AI 辅助选择和示例模型服务，自动确认开关关闭" caption="真实创建组件与隔离演示服务；先由 AI 分析，再确认分类。服务名和模型 ID 仅作界面示例。" />

**完成标志：进入“绿地提取”，看到 AI 建议的分类、置信度和分析依据。** “模型检查”负责读取文件和材质信息，不涉及三维建模操作。若已开启自动确认，可能直接进入后续提取或区域选择阶段。

::: tip “AI 辅助选择”不可选？
若面板提示没有配置完成的 Provider，表示还没有可用模型服务。先保存服务配置并测试连接，或改选 **手动选择**，按下方备选步骤自行分类。
:::

## 3. 复核分类并提取绿地

### 先看 AI 的建议，不必从空白列表开始

**每一行是一种材质，不是一块独立绿地。** 同一个材质可能被许多不相连的地面共用，所以一行材质最后可以提取出多个区域。

列表的**材质事实**帮助辨认来源；**规模**是使用该材质的模型面数和对象数，**不是绿地面积**。先检查已被归为绿地的项，再关注低置信度、依据不明确或与预期矛盾的项。

| 看哪里 | 用来判断什么 |
| --- | --- |
| **分类** | AI 建议把这一材质用于普通绿地、行道树绿地，还是排除为非绿地 |
| **置信度** | 分析对本次判断的把握程度；不是准确率承诺，也不是要种植的比例 |
| **分析依据** | 参考了哪些名称、对象或贴图信息，帮助检查建议是否合理 |

对某项有疑问时，可搜索材质名、对象名或纹理路径定位，再修改最右侧的分类。**AI 辅助缩小判断范围，最终提取结果仍要对照模型检查。**

<Shot src="/media/studio-material-classification.png" alt="绿地提取面板中的材质事实、规模、分析依据和分类下拉框" caption="分类可在最右侧调整；本图是已有项目手动恢复提取的界面，AI 分析时会在分析依据列显示置信度与依据。" />

### 最右侧“分类”怎么选？

| 分类 | 什么时候选 |
| --- | --- |
| **普通绿地** | 普通草地、花坛或成片的待种植地面；不需要单独区分时，用这一类 |
| **行道树绿地** | 希望单独标记、后面便于筛选的道路旁绿带等区域 |
| **非绿地** | 本次不提取的表面，例如道路、建筑、水面或不打算种植的地面 |

这一步**只标记区域类别，不决定种植策略或树种**。选了“行道树绿地”不会立刻生成行道树；真正种什么、怎么排布，要在后续植被种植阶段选择。

1. 核对 AI 建议的绿地项，必要时将分类改为 **普通绿地**或 **行道树绿地**。
2. 检查是否有需要补入或排除的项；不需要提取的设为 **非绿地**。不要为了“保险”把所有材质都标成绿地。
3. 点击 **确认并提取绿地**，等待任务运行完成，将这些模型表面整理为平面区域。

**完成标志：进入“区域选择”，画布上出现可供种植的面。**

### 备选：没有 AI 服务时，手动选择 {#manual-selection}

创建项目时选择 **手动选择**，模型读取完成后按同一张分类表操作；这种方式不需要在线模型服务。

::: details 展开手动分类步骤

1. **找到目标材质**：根据材质名、对象名或贴图路径搜索。若仍无法判断，可在建模软件中选中目标地面查看材质，或请模型提供者协助核对。
2. **逐项分类**：模型里的草地、花坛等待种植地面设为绿地；道路、建筑、铺装、水面等不种植的表面设为非绿地。名字像 `Material.0029` 也可使用，关键在于实际覆盖哪些表面，不能只凭“颜色是绿色”判断。
3. 点击 **确认并提取绿地**，后续检查与 AI 路径相同。

**如果草地与道路共用同一个材质，按材质无法只取出其中的草地。** 这不是换成 AI 就能消除的区分问题；应先在建模软件中分配不同材质，再重新导出 FBX。
:::

## 4. 确认提取结果

提取出的每块独立区域叫一个**面岛**；区域内部被排除、不能种植的空洞叫**孔洞**。它们描述区域形状，不是新的种植参数。

在 **区域选择**中缩放查看，先核对这三件事：

- **取对了地面吗？** 应与模型中的待种植位置对应，不应把道路、建筑侧面一起取进来。
- **分开和留空的位置对吗？** 不相连的绿地可以是多个区域；应避让的内部空地不应被填满。
- **面积看起来合理吗？** 若出现很长的细线、几乎没有面积的面，先检查模型几何，而不是直接开始种植。

这时**只是准备好了区域，还没有植被点位**。后续输出的时候会通过 Blender 从项目 FBX 模型取得地面高度，不需要再提供高程 TIF。

::: warning 已经种过，想重新提取？
调整材质后使用“重新提取绿地”会出现重置确认，影响现有选区和种植结果。不要把它当作普通刷新；先另存需要保留的 XML，再阅读确认提示。
:::

## 区域就绪，继续种植

**[进入工作台种植流程](./workbench.md#regions)**：选择本批区域 → 选用种植方案 → 预览点位 → 生成 XML → 在 DTS 验收。

## 在这里卡住了？

| 看到的情况 | 先检查什么 |
| --- | --- |
| 不知道选哪个材质 | 优先使用 AI 辅助选择，查看分类、置信度和分析依据；有疑问的项再结合模型复核 |
| AI 不可选或分析失败 | 检查服务配置、密钥、模型 ID 和连接状态；没有可用服务时改用手动选择 |
| 没取到绿地，或把道路也取进来了 | 检查分类及材质实际覆盖的对象；草地和道路共用材质时先修改模型 |
| 提示平面面积为零 | 竖直面从上往下看可能只剩一条线，不适合平面种植；请检查目标表面与模型几何 |
| 一直在分析或提取 | 查看项目任务状态和 Blender 可用状态；复杂模型的耗时不只取决于文件大小，不要连续重复提交 |

更多模型读取与几何问题见[常见问题](../reference/troubleshooting.md)。

## 配置 AI 模型服务 {#可选-配置模型服务}

::: details 展开模型服务配置步骤

模型服务负责辅助材质分类，不执行种植策略。推荐配置后使用 AI 辅助选择；没有可用服务时，仍可使用手动分类。

1. 打开 **运行 → 模型服务**，选择模板并进入配置；使用团队网关时可新建自定义服务。
2. 填写 API Key，在 **使用模型**中填写服务实际支持的模型 ID。模板不固定默认模型；支持模型发现时，可点击 **获取模型**，首次为 **保存密钥并获取**。已保存密钥不会回显，留空表示保留原值。
3. **保存配置**后点击 **测试连接**，再回到 FBX 项目使用材质分析并人工审阅。模型列表不是可用性保证；获取失败时可手动填写有效 ID，测试失败时检查协议、端点、密钥权限和模型名。

内置模板的协议与端点只读；不同端点应使用自定义服务。外部服务会接收本次用于分析的材质、对象和贴图引用等资料，先确认数据允许外发；使用在线服务还可能产生费用。API Key 存在系统凭证存储中，删除服务配置不会同时删除密钥。
:::
