# FBX 模型种植

<p class="lead">从模型里的绿地材质提取区域，分批种植，最后输出 DTS XML。</p>

## 1. 模型

从 DTS 工作台的项目入口选择 FBX 路线，创建项目并指定保存位置。项目会保留本次工作流需要的文件与状态。

<Shot src="/media/studio-workflow-source.png" alt="DTS 项目工作台的区域来源选择弹窗，包含 FBX 模型与 SHP / GeoJSON 两条路线" caption="在项目入口选择 FBX 模型作为区域来源" />

确认设置中的 Blender 路径有效。等待模型检查完成，查看模型与材质信息，不要仅凭文件大小判断处理耗时。

<Shot src="/media/studio-runtime-settings.png" alt="Studio 外部运行环境设置中的 Blender 可执行文件与 DTS Explorer 根目录，路径已遮挡" caption="配置 Blender 路径后检查可用状态；截图中的本机路径已遮挡" />

## 2. 绿地提取

根据材质名称选择需要提取的绿地。可手动设置；配置模型服务后，部分分类过程也可获得辅助，但仍应人工确认。

<Shot src="/media/studio-material-classification.png" alt="绿地提取面板中按材质设置普通绿地、行道树绿地等分类的列表" caption="按材质确认绿地分类；截图为已有项目恢复提取时的界面" />

同一材质不一定只对应一个连续面。提取结果以实际几何为准，可能包含多个面岛与孔洞。材质误选、重复面、退化面或垂直结构，都可能造成不适合 XY 平面种植的区域。

::: tip 先核对材质
如果提取结果与预期不同，先确认目标绿地材质的准确名称及其实际覆盖对象，再扩大选取范围。
:::

## 3. 区域选择

在画布中查看提取出的区域，选择本批要种植的面。尚未种植的区域继续作为空间参照；已经占用的区域不能再次随意叠加种植。

<Shot src="/media/studio-region-selection.png" alt="Studio 区域选择画布，显示本批选面、未选择区域和已保存批次的信息" caption="选择本批要种植的面，并保留周边区域作为空间参照" />

## 4. 植被种植

先选择 **预设方案**或 **手动配置**。已有方案时，选中方案并确认摘要即可生成；需要改变植被或效果时再调整方案。

手动配置分三步：

1. **种植方式**：选择策略卡片，并确认版本与信任。
2. **植被搭配**：按用途选择植被，可以切换兼容资产库继续添加，保留此前已选项。
3. **效果与预览**：调整参数，在策略样本中查看效果，再生成实际区域点位。

<Shot src="/media/studio-effect-example-v031.webp" alt="效果与预览面板，参数与策略样本并排展示" caption="真实组件与合成样本；示例不是当前项目选区" />

效果合适时保存为[种植方案](../resources/mixes.md)，下次直接复用。正式随机种子在高级设置中调整，不写入方案，也不改变示例固定种子。

## 5. 点位预览

按批次展开植被图例，保留或排除具体资产。预览反映已经分配的植被，不再以策略角色作为图例。

<Shot src="/media/studio-point-preview.png" alt="点位预览画布与批次侧栏，展示参考范围、批次开关、植被图例和输出入口" caption="在点位预览中按批次与植被筛选保留结果" />

效果满意后可以继续种植其他区域。想修改某一批，使用该批的重新种植操作，详见[多批次与点位预览](../manual/batches.md)。

## 6. 输出

点击 **输出预览点位**进入输出面板，核对保留数量并按需设置 XYZ 坐标偏移。再点击 **生成 XML**，系统为所选批次补齐或复用高程，最后按当前筛选生成一份 XML，详见[输出流程](../manual/output.md)。

<Shot src="/media/studio-xml-output.png" alt="XML 输出面板中的坐标偏移、历史 XML 列表、另存为与删除入口" caption="XML 留档管理示例；图中本次保留为 0，需先保留点位才能生成新文件" />

XML 成功生成后会保留在项目输出列表，直到手动删除。回到前面的阶段继续种植，不应清除已有输出文件。

## 提取耗时或失败

复杂模型的导入、面岛处理与边界整理可能耗时较长。重复重启不一定能解决问题。优先确认任务阶段、Blender 配置和模型几何，再看[常见问题](../reference/troubleshooting.md)。
