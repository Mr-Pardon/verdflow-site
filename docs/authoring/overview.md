# 创作与扩展

<p class="lead">从创作一种种植方式，到连接新的区域与目标工具，让成果在共同的工作流中复用。</p>

## 理解 VerdFlow 的设计

VerdFlow 将区域准备、策略生成、植被分配、高程采样与目标输出分开，再由共用核心串联。Studio 和实时面板是操作入口，策略与数据不必随着界面的变化重新设计。

[架构与扩展](./architecture.md)用一张流程图说明这些部分如何协作，以及哪些能力已经可用、哪些仍是后续方向。当前完整使用路线以 DTS 为目标。

## 选择你的参与方式

| 你想做什么 | 从这里开始 |
| --- | --- |
| 理解整体设计，评估新的输入、输出或工具接入 | [架构与扩展](./architecture.md) |
| 设计空间关系、分布算法与参数 | [理解策略角色](./roles.md) → [VFS Author](./strategy.md) |
| 将已有植物资料整理为可复用资产信息 | [VFA Author](./assets.md) |
| 使用现有策略换植物、调整效果并保存 | [种植方案与植被搭配](../resources/mixes.md) |

策略和资产可以通过现有标准包导入；新的适配器或客户端接入仍需要开发与验证。

## 两个作者工具包

| 工具 | 用于 | 最终成果 |
| --- | --- | --- |
| VFS Author | 设计空间分布算法、角色与参数 | 可导入的 `.vfs` 策略包 |
| VFA Author | 整理植物文档、分类、图片与目标资源信息 | 可导入的 `.vfa` 资产包 |

Skill ID 分别为 `vfs-author` 和 `vfa-author`。它们提供模板、约束和创作方法，不是要求用户额外购买或配置的另一种模型服务。

在 Studio 对应资源库导出作者工具包，解压 ZIP 后将 Skill 与模板提供给你熟悉的 Agent。具体安装方式由使用的 Agent 工具决定。

## 一条可审阅的创作路线

1. **说明意图**：要解决什么空间关系或资料整理问题？
2. **确认事实**：明确角色职责、输入数据和可靠来源。
3. **生成成果**：按模板实现算法或整理标准目录。
4. **检查与验证**：审阅数据、代码、边界与重复生成结果。
5. **导入小范围测试**：确认正确后再投入正式场景。

Agent 可以帮助实现，但不应该替你猜测真实模型名、把概念图当实测，或把未验证的算法包装成可靠成果。

## 当前不包含什么

这条路线不提供产品内自动运行 Agent、完整策略编辑器或未经人工确认的智能资料导入。外部创作完成后，以标准包回到产品边界。

第一版资产作者路线面向 DTS。不要把尚未推进的 Blender 资产工作流写入交付承诺。
