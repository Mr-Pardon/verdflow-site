# 把植被资料整理成资产库

<p class="lead">保留可靠事实，让来源复杂的植物资料回到一个标准目录。</p>

## 1. 提供资料与模板

在资产库获取 VFA Author 工具包，将 Skill、模板和你的 PDF、表格、图片或目录交给外部 Agent。

说明资料的权限与用途，要求保留分类和可靠来源。含有未公开项目资料时，先脱敏并确认允许上传到所选 Agent 服务。

## 2. 先确认事实字段

| 字段 | 可靠来源 |
| --- | --- |
| 显示名称 | 植物目录或人工确认 |
| DTS 目标模型名称 | 资料明确记载或场景资源核对 |
| 分类与标签 | 原资料分类或确认后的整理结果 |
| 缩略图 | 可提取且有权使用的原图 |
| 建议缩放 / 参考半径 / 参考高度 | 明确测量或人工录入 |

模型名称最重要。它可能是拼音、英文、缩写或资源内部命名，不能凭植物中文名自动编造。

## 3. 处理不确定信息

让 Agent 区分“原文明确”“人工确认”“缺失待补”，把冲突列出来。缺失参考半径或参考高度可以留空，不要用植物的常见成年尺寸假装是某个模型的真实尺寸。

高度不是半径，图中的比例人物也不等于可靠测量基准。必要时人工填写，且说明这是参考值。

模板支持可选的 `reference_height_m`，表示模型在 100% 等比缩放时的竖向参考高度，填写时为有限正数。它不是地形高程，也不会自动调整点位、策略间距或 XML。

## 4. 整理分类与图片

保留原资料有意义的分类，可让一个植被属于多个 Collection。合并同一资产的重复记录前，核对目标资源名，不要只看显示名称。

缩略图使用受管文件并随包携带，避免引用临时目录或绝对路径。裁切时优先保留可辨认的植被主体，并检查分享权限。

## 5. 校验与交付

按当前模板生成 `.vfa`，检查字段、引用、分类关系与图片，再附上未确认项清单。

导入 VerdFlow 后核对数量、分类、缩略图和几个关键资源名。最后在 DTS 中执行小范围验证，确认模型实际可用。

## 给 Agent 的开场要求

```text
请阅读 VFA Author Skill 与模板，整理这份植被资料。
保留已有分类，提取可靠模型名称和有权使用的缩略图。
不要推测未知 DTS 资源名，不要把高度当参考半径。
缺失或冲突字段列为待确认项。完成结构校验后，
交付 .vfa、来源说明与人工核对清单。
```

当前作者路线面向 DTS 信息目录，不包含三维模型安装或 Blender 资产导入承诺。
